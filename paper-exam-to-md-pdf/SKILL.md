# 纸质试卷转 Markdown/PDF

用户只给“链接＋转录”时直接执行。默认先交付一份完整 Markdown，保留原文已有答案解析；PDF、学生版或双版仅在本次明确要求时生成。微信公众号先用 `weixin-article-to-pdf` 取得原文与原图；纯网页正文用 `baoyu-url-to-markdown`，说明不需要 MinerU。已有同一 URL 的提取结果先核验后复用，避免重新抓取。

## 默认路径

1. **来源与识别缓存**：使用 [scripts/transcribe.py](scripts/transcribe.py) 的 `prepare`、`ocr`；以来源 URL、文件 SHA-256 和解析配置识别缓存。当前无 MinerU MCP 时继续检查本机 `mineru-open-api`/现有服务，不能据此让用户重复配置。复杂公式优先 MinerU VLM 精确识别；快速文字草稿可用 Flash，回退须说明实际通道。私人本地文件远程 OCR 仍需逐文件授权，不能用缓存开关绕过。
2. **先定位，再读题块**：`summarize-ocr` 将重复题干差异、题号、版面坐标和缺选项疑点写入本地 JSON。先读摘要，再按题读取候选与原图；不要默认将整份 OCR、JSON、成功编译日志送入模型上下文。异常清单是定位工具，未列出的题目仍需满足原图核对要求。
3. **唯一题目数据**：题干、原答案解析、校注、来源与复核证据存于工作目录 `题目数据.json`；题目版和解析版由同一题干生成。新材料按 [数据约定](references/incremental-workflow.md#题目数据) 建草稿，不自动猜测题目边界；已有校订双版用 `import-reviewed` 导入。学校、年份、题号及特例修订放入本次运行数据，不写死在通用脚本。
4. **按图校订与复核**：逐页核题号、条件、公式、选项、分值、小问和题干结尾。复杂公式、低清、跨页、几何图、OCR 冲突重点放大。`crop` 按实际 OCR 输入 PDF 的页码及归一化坐标裁图，打开局部图确认顶点、线条和标注完整；不得用整页截图代替正文题图。原图保持只读，来源水印不得擦除、覆盖或模糊。原始整页图在文末附录集中链接。
5. **增量构建**：`plan` 只报告变动题号、结构错误及过期复核；修订在 JSON 中按题进行。`build` 默认只生成完整 Markdown；本次要求 PDF 时加 `--pdf`，要求双版时加 `--editions student,teacher`。固定模板处理中文、圈号、∵∴、中文单位、题图不浮动及短题同页；长题允许自然分页。正文/图片/模板未变化时跳过编译与预览，变化后只重建受影响版本，重点查看受影响页。
6. **验收**：脚本检查题号、选项、公式分隔符、链接及答案分离；真实编译检查缺字、超宽、未定义命令；看最终首页、公式/图形密集页、末页及受影响分页。没有目视看过的预览不能登记“已检查”。程序检查、原图一致性和数学独立解答分开报告。

命令示例、数据格式、缓存边界与恢复方式见 [references/incremental-workflow.md](references/incremental-workflow.md)，需要操作时再读。仅排版已有稿可直接调用 [scripts/pdf_export.py](scripts/pdf_export.py)，显式传入文件；不得通配扫描并编译整个输出目录。

## 内容与交付边界

- 默认完整 Markdown；有原答案时保留其有效正文。仅在要求题目版时分离答案、解析、提示或解析辅助图。不因“转录”自动补写新解法、分类讲义或教学点评。
- 原文笔误与 OCR 错误分开：识别误读按原图改；原文本身存在疑点时照录并另列校注。不能确认的条件、公式或图号记录页码、题号、候选、原图位置与状态，不静默补全。
- 数学正文使用 Markdown LaTeX，保留全部小问与必要题图。来源材料、识别草稿、版本与恢复依据留在本次工作目录；脚本所在技能目录只存代码与模板，不存学生资料、凭据或运行缓存。
- 复杂文档与数学核对应依适用 AGENTS.md 做独立复核。向子 agent 提供最小文件路径、范围与标准，优先不继承无关历史；返回位置、差异和证据。并行能缩短时间，不保证节省总 token。按图核对不能声称已独立重解。
- 最终文件用中文语义化名称，放在 `outputs/`，中间文件和日志放在 `work/`。不覆盖原始、并发或人工改动的输出。
- 同来源续做优先回到已登记的工作目录和识别收据；缓存目前是工作目录内缓存，不能换目录后宣称自动跨任务命中。已有结果可通过 `--source-index`、`--ocr-md/--ocr-json` 显式导入，先核对输入哈希，不重复上传识别。新安装、全量备份、整套素材复制均不能作为绕过缓存异常的默认重试。
- 原稿/必要恢复点与可再生预览分开；双版共用题图，不各复制一套图片。未要求 PDF/双版/ZIP 不额外生成。收尾记录主要新增占用，自动清理仅限本任务明确拥有且已授权的临时产物，不按年龄清理来源和会话。
- 收尾交付路径、真实页数与已检页码、疑点与未核范围。记录调用次数、耗时与摘要字符数；未取得会话 token 计数时写“未测量”，不将字符节省换算成 token 节省。
