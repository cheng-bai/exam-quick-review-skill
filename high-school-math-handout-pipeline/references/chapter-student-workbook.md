# 章节分层学生作答版

适用于从数学学生版题集重建可打印的章节练习册，以及随后调整难度分组、作答区和生成页眉。不是自动去除原始出版来源的工具。

## 入口与复用

- 先查本任务已有题源、识别结果、清单、构建脚本和成品。PDF 有书签时用 PyMuPDF `get_toc()` 定位章节，并与章节首页及正文标题核对；不能把书签存在当作章节边界已正确。
- 有同源 Markdown/TeX 时优先复用，抽核公式、题图、题序及来源与指定 PDF 的对应关系；不同版本不得仅因文件名相似直接替换。仅有 PDF 时提取并逐题核对；只需原页切块留白则用 `pdf-question-space`，无需转录重建。
- 先记录预计章数、题数、图数和待核项，数量从当前输入计算，不把历史案例数量写成默认值。用户要求全量完成时，首章样张只是内部检查点，不代替全量交付。
- 仅执行请求的层级：只拆章不擅自分难度；要求分层时才启用下述分组；只改页眉则冻结现有题序与版式。

## 一份题目清单

每题至少保存：稳定 ID、原题号、章节、来源页或段落、完整题干与小问、选项、题图引用、原待核提示。分层时另记难度、简短依据与置信状态；排版时记题型及留白设置。

- 原始 ID 不随排序变化，展示序号可调整，并保留映射。
- 跨页题先合并完整题干、选项与题图，再排版；孤立数字、分母和圈号不作新题号。
- 对账采用稳定 ID 的集合与出现次数，不只看总题数。输入每题在成品恰好一次；确需重复展示须单独记录。
- 题图路径须可解析，图号与选项配对；原待核题仍须收录并显著保留待核状态，不能把排版完成写成数学已审定。

## 章内难度分组

按用户指定的 `简单 → 中档 → 难题` 在每章正文实际分组，组内默认保留原顺序。不用一张索引代替正文重排，也不为填满三组强行均分；空组可省略并在索引记为零题。

| 分组 | 教学判断依据 |
|---|---|
| 简单 | 常规概念或公式直接应用，入口明确，必要转化较少 |
| 中档 | 需要选择方法、连接多个条件，或有一定运算与分类 |
| 难题 | 入口隐蔽、综合转化较强、参数边界复杂或有明显证明障碍 |

依据题目结构而非题号、字数、是否解答题或已有留白判断；长题不必然难，短填空也可能难。完整多问题默认保留为一题，以关键障碍综合判断，不机械拆散共享条件。分组是面向目标学生的教学估计，不冒充实测难度或完整数学审校。存在明显疑点时针对性复核，不为分层自动补写整批答案。

索引至少列章节、稳定 ID/原题号、分组和来源，便于回溯与后续调组。学生正文不默认加入方法提示或分组理由，版本合同仍以主技能和本次请求为准。

## 排版和作答区

- 采用 `lecture-pdf-layout` 的学生练习版式：A4 单栏、清晰题号与组标题、真实上下分式、低干扰页眉页脚；首章样张通过后复用模板构建全章。
- 简单填选可先试 3 行、证明题 10 行、多问长题 16 行；这些只是初始化值，按实际书写需求、纸面空间和用户用途调整，不以减小字体或任意压缩大题留白来凑页。
- 多问题按各小问提供可辨认的作答区域，明确题号/小问对应。原文没有小问标记时不得靠猜测插入题干；可在题后列相应答题区。
- 测量题干、图形、题号和作答区的总高度。当前页放不下则整体移到下一页；不能只保证题干完整而将书写区挤走。
- 若单题超过单页，先检查冗余段距、图片排列及选项平铺，在图形和文字可读的前提下调整。仍无法容纳时记录该题并说明需要的取舍，不静默裁掉内容、极度缩小或放开分页；需要改变交付要求时再询问。
- 图形相邻排布只限语义对应明确的情况；保留 A/B/C/D 与图号，防止重排导致选项错配。
- 检查圈号等特殊字符字体覆盖；编译无报错不等于没有缺字。长题高度告警必须逐项处理，不能以能生成 PDF 为验收。

## 指定页眉字样清理

用户称“水印”时，先渲染确认实际对象。对本流程生成的装饰页眉，授权删除指定字样后优先改共享源模板重新编译，保留章节名、来源与题图；不要用整页截图、白色遮盖或全局字符串删除误伤正文。输入原件的来源标识不属于本操作授权范围。

只改页眉时，逐页核对新旧页数和尺寸；提取文字仅允许指定页眉差异，正文、题号与待核提示不变。PDF 提取可能改变空格形式，应按实际提取结果仅对页眉片段规范化，不对整篇公式随意删除空白。另渲染受影响页眉区域，核对指定字样确实消失、没有误删；文本比对不能证明图形未变。若模板变更引起正文重新分页，检查并修复，不忽略页数变化。

## 全量验收与交付

1. **清单对账**：章节边界、稳定 ID 唯一性、题数、各组数量、来源与图引用；核对所有计划章节实际生成，保留残余疑点列表。
2. **结构检查**：全部 PDF 可解析、页尺寸符合目标；用 `qpdf --check` 或可用等效工具检查。编译日志筛查 `Missing character`、`Overfull`、致命错误及构建器长题告警，定位后修复并重跑受影响项。
3. **视觉检查**：每章首末页、难度组切换、跨页原题、多图选项、多问作答区和最长题优先检查；记录实际查看页，抽样不得称为逐页目视检查。结构检查、视觉检查、数学复核分开报告。
4. **复核**：批量重排由独立 agent 检查题目完整性、分组合理性与实际可书写性；无法委派时第二遍自查并说明限制。复核不能把未核的数学题自动标为已核。
5. **冻结成品**：保留原文件，不覆盖不相关版本。按用户位置交付章节 PDF、分层索引及简短交付说明；源文件和必要依赖按请求收齐。用户要求打包时生成含相对依赖的 ZIP，并用 `unzip -tq` 或同等方法验证；合订本、教师版和外发均不自动追加。

交付说明给出实际章数/题数/页数、分组估计口径、检查覆盖、待核项及路径；不得将“构建成功”写成“全题数学无误”。只交付最终文件，日志、中间渲染与恢复点留工作目录。

## 本地案例复用边界

本流程来自 FY27 学生作答版的章节重建、难度重排与生成页眉清理。旧任务脚本可能包含固定题源路径、编译器位置、章数及个别题图修补；可作为适配线索，不能直接作为通用脚本运行。先从当前环境解析可用编译器与依赖，显式传入本次源文件、输出目录和清单；不得为复现历史案例重新安装整套环境或复制整套素材。
