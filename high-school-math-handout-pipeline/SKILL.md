# 高中数学讲义流水线

## 概览

把粗糙来源或 OCR 材料整理成可上课使用的分类讲义包：学生版用于练习，教师版用于讲评、诊断和授课。核心原则：不要只是美化 OCR，要按题型和方法重建材料，校对数学，再验证渲染后的 PDF。

## 入口与内容冻结

先按本次请求选择模式，不额外询问已明确的信息：

- **只导出已确认内容**：现有 Markdown/TeX 已经定稿，用户只要 PDF 时，直接交给 `lecture-pdf-layout` 及必要的渲染/PDF 检查；跳过本流水线的提取、分类、补写。冻结题号、顺序、题干、答案和来源，仅调整版式；实质数学错误另记勘误后修正，不静默重写。
- **重建讲义**：用户要求分类、补解或教学重组时，执行下文流程。只生成用户要求的学生版、教师版或双版本；未指定且无法从用途判断时只问版本这一个关键问题。
- **章节分层作答版**：用户要求“分章节重新制作”“每章按简单、中档、难题分组”“留作答区”或继续修改该类成品时，阅读 [章节分层学生作答版](references/chapter-student-workbook.md)。复用已核对题源与清单；不因学生版排版任务自动补解或重算全部答案。
- 每题沿用稳定题号或“来源缩写＋原题号”，连同来源位置、核验状态交接。单版本任务不因下文双版本示例而扩大范围。

## 内容版本合同

“学生版”不自动等于无分析。根据请求与已确认上下文确定栏目，明确指令直接执行，不重复确认：

| 版本 | 保留内容 |
|---|---|
| 纯题目版 | 完整题干、小问、选项、必要图、学校/学期/原题号，不混入答案解析 |
| 含本题分析版 | 纯题目内容＋逐题完整原“本题分析”，包括原考点、预计难度、易错提示等 |
| 完整教师版 | 完整题干＋答案解析及授权的教学备注 |

原分析可能含方法或结果提示；用户授权时保留，以“含本题分析”命名，不声称无提示。恢复该栏目不自动恢复参考答案/参考解析。原题提供的引理、示例和证明属于题面，不按答案关键词删除。上述合同优先于下文学生练习默认。本地已有题下分析的分类汇编，若当次未要求去分析，默认沿用含本题分析版；纯题目/无提示/去分析请求覆盖此偏好。不将这个本地默认套到正式考试或没有原分析的材料。

## 必用/配套 skill

- **必用：** `lecture-pdf-layout`，用于按学生练习/教师阅读用途选择 A4 LaTeX 讲义版式。
- **编译：** 独立 `.tex` 按宿主要求使用内置编辑器与编译工具；批量 PDF 构建按已有可用流程使用本机 `xelatex`，先用 `command -v xelatex` 解析真实路径。
- **按需：** `math-markdown-pdf-polisher`，当来源是 OCR Markdown 或 MathJax/HTML 打印输出。
- **按需：** `ocr-math-teacher-book-pipeline`，当目标是整本 OCR 教材教师版、章节 PDF、可见目录、细粒度书签和审计报告。
- **按需：** `pdf` 或 OCR skills，用于读取、裁剪、转换、检查 PDF/图片。

## 工作流程

1. 确认源文件绝对路径，把所有输出写入当前任务工作区；原始文件保持只读。
2. 完整提取题集：题干、图片、答案片段、OCR 疑点和原始顺序。
3. 写最终讲义前，先建立 `题号 / 来源位置 / 题型 / 核心入口 / 当前答案 / 风险` 表。
4. 按用户要求的教学结构重排。章节分层模式按参考文件执行；方法分类模式按共同方法分组，如旋转函数判定、圆锥曲线焦半径、概率模型、几何坐标、新定义、应用建模等。
5. 重建/补解时审计解答；已有可信解析且本轮只分类、保留分析或导出时，聚焦内容对应、实际疑点和版式，不额外独立重算整批答案。矛盾处记录并针对性复核，保留修正依据或待核标记。
6. 只生成请求的版本；双版本时尽量用一个 master source 同步生成：
   - 纯题目学生版：题目、图形；方法分类模式可附模块地图，章节分层模式不强加地图。仅授权提示时增加简短思考切口，不含答案。
   - 教师版：同顺序，加答案、推导、易错点、讲评建议和总结。
   - 最终学生版、教师版、质量报告等 Markdown 交付文件必须按内容含义使用中文语义化文件名，例如 `圆锥曲线专题讲义-学生版.md`、`圆锥曲线专题讲义-教师版.md`、`圆锥曲线专题讲义-质量报告.md`；不要用 `source.md`、`student.md`、`teacher.md`、`cleaned.md`、`QUALITY_REPORT.md` 这类泛名或英文名。
7. 套用 `lecture-pdf-layout`：按学生练习或教师阅读选择留白与密度，保持 A4 单栏；颜色用于功能区分。
8. 编译并验证本次要求的 PDF；双版本才做双版一致性检查，未通过就修复受影响项。
9. 只把最终交付文件复制到用户可见 `outputs/`，汇报路径、页数和残余风险。

## 整书教师版模式

如果用户要把整本 OCR 教材变成教师版，不要停在章节 PDF。完整交付应包含：

- 题后下置答案的教师版 Markdown。
- 答案配对审计，证明每个目标题块只有一个答案块。
- 结构审计，证明标题层级出版化且 OCR 页码标题残留为 0。
- 章节 PDF 和一个合并 PDF。
- 插入合并 PDF 的可见目录。
- PDF 书签至少到章内单元，如 `神器` / `热点` / `综合基础强化`，不只到章级。
- 构建报告：目录页数、最终页数、书签数量、书签页码目标。

外部答案文件若章节体系不同，只能作为审计辅助，不要硬配进书里。

## 分类规则

以下为方法分类模式。章节分层模式优先遵循 [章节分层学生作答版](references/chapter-student-workbook.md)，不额外强加方法模块、模块地图或方法分类书签。

优先采用对课堂有用的顺序，而不是来源顺序。用“知识板块→考点专题→操作题型”组织；选择/填空/解答是题目形式，不能代替具体分类。按所求对象、关键转化与边界拆分，不固定类数。完整大题默认收一次，跨类小问用引用保留整题依赖；重复展示另计次数。

分类必须落实到正文分组标题、紧凑目录和PDF分类书签，不能只有台账。大板块拆分册并保留整册入口；用户要求更细时先复核边界，再同步所有入口。

| 材料模式 | 更好的分类 |
|---|---|
| 多道旋转/对称问题 | 垂线交点、相对运动、切线边界一组 |
| 共享焦点的圆锥曲线问题 | 焦半径和差、共焦关系、交点分类一组 |
| 概率/计数混合几何 | 按样本空间模型、主变量、坐标/空间建模拆分 |
| 新定义或真实应用题 | 放在核心方法模块之后，除非它本身引入必要入口 |

每个模块开头给一个紧凑地图：`模块 / 共同题眼 / 涉及题目`。地图不能替代实际讲解。

## 成果整理

多版本或用户要求整理时，建立统一阅读入口，最新含分析版、完整教师版、纯题目版与教研报告按用途分开；合订PDF、分册PDF、Markdown各自成层。台账/勘误/复核、必要来源图片、复现数据脚本另放。只建实际需要的目录，草稿、日志和备份留工作目录，原文件保留。

共享包收齐引用来源与图片，改成包内相对链接；核对副本哈希、题干/公式不变、链接目标。解析链接时避开数学定界和代码，不能将方括号与圆括号相邻的因式乘法改成文件链接。脚本绝对路径未便携化时说明复现限制。无需为本地整理自动压缩或外发。

## 数学审计

安排独立复核时，首轮只提供题干、范围条件和必要图形，先记录独立答案与证明骨架，再提供原解比较。不要在首轮透露预期结论；已看过原解则注明为对照复核。数学复核、结构检查和视觉检查分别记录，不能互相替代。

在本轮重建、补解或疑点触发的解答审计范围内，检查以下项目；仅分类/导出时不因此扩大到整批数学重算：

- 定义域和存在性：函数值、参数范围、端点、排除斜率、分母非零、重根、有限交点。
- 等价方向：必要条件不能未经证明当充分条件。
- 计数样本空间：空/非空、有序/无序、放回、独立性、条件空间。
- 几何/圆锥曲线定义：焦距和差、共焦条件、角度/余弦、切线和渐近线边界。
- OCR 残留：坏 `\frac`、符号错、答案片段残留、重复图片、乱码中文。

答案口径可能有两个时，教师版必须说明约定，如 `按严格定义` 或 `按原题意宽口径`，不能静默选择。

## 讲解风格

纯题目学生版默认（含分析版按上方合同）：

- 思考切口仅在用户允许提示时添加，一句话说明入口变量、判定条件或关键边界；无提示请求不添加。
- 不包含答案、最终答案暗示或长推导。
- 图形贴近对应题目。

教师版：

- 每题解答从 `答案` 开始，再给直接 `解析`。
- 解析按一个推理动作一个独立步骤排版：确定条件、分类、计算、验边界、合并结论各占可批注的列表项或短段落。不要依赖 Markdown 单个软换行；预览中确认步骤没有合并成一段。简单题按实际需要写，不机械凑步数。
- `易错点`、`讲评建议`、`高观点` 只在确实有教学价值时添加。
- 总结要帮助迁移，例如“这一类归结为垂线交点判定”“这一组圆锥曲线归结为焦半径和差”。
- 短公式用行内 math；长推导、方程组、分段讨论或最终强调才用 display math。

## 版式约定

- 第一页要有真实教学内容，不做营销封面，除非用户要求。
- 学生版和教师版题目顺序、模块结构一致。
- 可行时用一个 master `.tex` 加 teacher/student flag 生成；否则保留版本映射检查。
- 可以清除模板自带的示例品牌、占位署名和与正文无关的独立二维码/推广页。用户明确要求删除本次生成的装饰页眉或其中指定字样时，先判断是页眉、背景还是题图内容，优先修改源模板并重新编译，仅改变指定区域；具体差异核验见上述作答版参考。不得把这一授权扩展为移除输入资料中的真实出版社标识、发布者水印或必要来源信息；无法确认属于模板还是来源时默认保留并说明。
- 盒子只用于解答、提醒、方法等有功能的内容；不要嵌套盒子或装饰性卡片。
- 教师版可紧凑，学生版留白按用途；用户要紧凑汇编时不强加大块答题区；题目分页不好时，优先调附近间距和盒子可分页性。

## 验证

完成前对本次生成的 PDF 和主源做内容一致性检查。以下为批量双版本命令示例，单版只检查对应文件，并替换为实际路径：

```bash
XELATEX="$(command -v xelatex)"
PDFINFO="$(command -v pdfinfo)"
test -x "$XELATEX" && test -x "$PDFINFO"
"$PDFINFO" outputs/student.pdf | rg 'Pages|Page size|File size'
"$PDFINFO" outputs/teacher.pdf | rg 'Pages|Page size|File size'

rg -n 'Missing character|Fatal|Emergency|Undefined control sequence|Overfull \\hbox' build-student/student.log build-teacher/teacher.log || true
```

还要查看实际渲染页面，并记录总页数、已检页码、检查方式（缩略图或原尺寸）和发现项；抽查不能称逐页审阅。确认：

- 源题数等于最终讲义题数。
- 所有图片本地存在，并出现在预期页面。
- 没有近似空白页。
- 没有公式裁切、文字重叠、图形丢失、图片文件名外露。
- A4 纵向、页数合理。
- 纯题目版没有混入答案解析；含分析版逐题保留授权分析且未多加答案栏目，不能将授权提示当作误泄漏。
- 教师版有答案；教学备注按实际教学价值添加，不为通过检查强凑。
- 最终 Markdown 交付文件使用中文语义化文件名。
- 源答案修正写进教师版，而不是只在最终回复说明。

命令不可用时，寻找 bundled 等价工具；仍无法运行就明确说明缺失检查。

## 迭代检查

首次可验证输出后，按“明天就要上课”复查：

1. 顺序是否符合教学自然性。
2. 哪些讲解是在纠正来源，而不是复述来源。
3. 哪些题需要更短入口提示或更清晰教师备注。
4. 是否有争议答案需要双口径说明。
5. PDF 是否像专业讲义，而不是 OCR 文本贴进盒子。

每批修订后重新编译并重新验证。

## 常见失败

| 失败 | 修正 |
|---|---|
| 只按来源顺序美化 | 按共同方法重建模块并加题型地图 |
| 教师解析只是计算 | 加入口、学生易错点和讲评句 |
| 学生版泄露答案 | 用 flag-controlled master 并 grep 答案标签 |
| 短公式被做成大公式块 | 改为行内 math |
| 源答案矛盾但被照抄 | 在教师版标明修正和口径 |
| PDF 编译成功但版式差 | 查缩略图；XeLaTeX 成功不等于视觉合格 |
| 整书 PDF 难导航 | 加可见目录和单元级书签，插入目录后重算页码 |
