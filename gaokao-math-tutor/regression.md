# 行为验收用例

用例用于修改后的实际回答检查，不是已运行结果。评审同时检查正确性、任务完成度、篇幅是否有用途；不能只检索回答中有无某个词。允许不同的正确写法与方法。

| 编号 | 用户输入 | 必须达到 | 失败信号 |
|---|---|---|---|
| R1 | 求 $f(x)=x^2$ 的导数，只要答案。 | 直接给 $2x$，无需其他环节 | 固定五步、方法总结或追问 |
| R2 | 已知 $f(x)=x^3-3x^2+2$，求单调区间，我不会。 | 求导、判号并完整给区间；两个增区间分别成立 | 停在求导问题；把增区间并集整体称为严格递增 |
| R3 | 同题，但用户要求“先别给答案，一步一步问我”。 | 仅推进一个有用步骤并等待 | 泄露完整解答；一次提多个问题 |
| R4 | 已知 $\sin\alpha+\cos\alpha=\frac12$、$\alpha\in(0,\pi)$，为什么差 $\sin\alpha-\cos\alpha$ 取正？ | 利用正弦为正和乘积为负确定差为正 | 重做全题；只说“由范围可知”而不连接依据 |
| R5 | 学生写 $\sqrt{x^2}=x$，怎么讲？ | 给正确关系、负数例子及具体讲法；原因未定 | 给学生贴标签；要求教师先算；擅自做整课教案 |
| R6 | $f:\mathbb R\to\mathbb R$ 满足 $f(x+y)=f(x)+f(y)$，且正输入时函数值为正。怎么给学生讲它严格递增？ | 任取 $x<y$，用 $f(y)-f(x)=f(y-x)>0$；可作直观对应 | 暗加连续或可导；只靠图像或数值例子 |
| R7 | 已知实数 $x$ 满足 $x^2=1$ 且 $x\le2$，求 $x$。 | 完整得到 $x=\pm1$；允许冗余条件 | 强迫每个条件发挥作用或漏负根 |
| R8 | 若 $a,b>0$ 且 $a+b=2$，证明 $ab\le1$。 | 用 $(a-b)^2\ge0$ 等高中方法得出结论，交代等号 | 把合法单向推出视为错误；数值代入充当证明 |
| R9 | 证明任意实数 $x$ 都有 $x^2+x+1>0$，用 $x=0,1,-1$ 验证过了就行吧？ | 指出有限检验不足；用配方完成一般证明 | 认可特殊值能证明“任意” |
| R10 | 图片里是 $a>0$ 还是 $a\ge0$ 看不清，问能不能除以 $a$。 | 核实该符号；先分别说明零值对除法的影响 | 猜成严格大于并直接相除 |
| R11 | 把这套已有答案的试卷做系统审校，并排成 PDF。 | 转入审校及排版流程，保留来源与原解；传递未决项 | 只给聊天题解；自动覆盖正式题库 |
| R12 | 只解释这份参考答案从第3行到第4行为什么成立。 | 对准已有材料的两行解释；看不到材料则问该处内容 | 重新求解整题；要求提供与该步无关的学生资料 |

回归通过不等于数学能力或真实教学效果已有统计提升。若回答仍被固定流程拉长，或出现高中范围外的替代证明，修订对应规则并重跑受影响用例。
