# 快评出版与受众投影（旧版参考）

> 当前交付以 [前端与教师后端通用框架](audience-framework.md) 为准；以下旧版内容仅供排版技术参考，与新版冲突时不执行。

## 默认交付

默认交付学生家长前端快评 PDF；教师讲评 PDF、PNG、Excel 和 Markdown 按用户要求从同一底稿生成。默认不制作网页，不交 Excel 截屏充当宣传图。

- **教师讲评 PDF**：A4，最上方必须有整卷说明，含来源、年级学期、题量、主要考查内容、结构难度、讲评顺序。正文“逐题评价 → 完整题目及原图 → 考点 → 答案 → 解析”，同题就地可读。长题与长解析允许续页，题头不孤悬。已有可靠解析则校核后复用，不能把答案摘要假装完整解析；缺解时先完成可靠快评，补解按学科流程核验，交付明确实际覆盖范围，不能标为完整讲评。不得为了固定页数缩小到难读。
- **整卷快评 PDF**：篇幅按内容决定，可采用合册结构。首屏先交代真实学校/考试节点与整卷判断，再列模块题量和主要要求、难度分布、带题号的三处重点、学生能执行的订正建议。少用内部术语。只有题量无分值时不能把题量占比写成分值占比。完整快评须包含原题证据、答案与分步解析，并按内容分页；现有脚本限单页，只能辅助制作概览草稿，不能替代合册。
- **简版 PNG**：独立排版，通常1200px以上宽，白底或极浅底、学科色标题、清晰表格与短句，手机打开可读。保留整卷看点、模块概览、代表题号与行动提示。不得缩整本PDF或Excel成一张图。不默认加二维码、电话、虚构案例、合格线、优秀线或提分承诺。
- **教师 Excel/底稿**保留题号、星级依据、知识树定位、原卷疑点、核验范围；对外版本省去本机路径、OCR日志与技术流程，不隐瞒影响结论的实质疑点。未核题可以不做确定性宣传，必要时简短注明范围。

## 配色单一来源

读取 assets/subject-colors.json：accent 用于细线和强调，ink 用于彩色文字，tint 用于浅色底；正文深灰，表格浅灰细线，避免大面积饱和底色。颜色通过一份配置应用到PDF、PNG与Excel。当前语文红、数学绿、英语橙、化学紫、生物粉均为用户截图近似色，不是源代码精确值；物理为用户确认的浅蓝色，具体色值为视觉近似；取得准确色值后替换。不得把南京图里的数学蓝/英语紫误当用户当前配色。用户提供工作台色值时优先更新配置；深色正文需保持浅底可读。

## 可选概览与简图命令

依赖 Python 3、Typst、Poppler（pdfinfo/pdftoppm）；不含OCR与学科推理。此命令只生成单页概览和简图，不会生成含原题与详解的正式合册或教师版；超出单页时应改用可分页排版，不缩小字号硬塞。正式成品另行制作并逐页验收。

```bash
python3 scripts/publish_review.py 评价底稿.json 输出目录
```

沿用 references/data-contract.md，在同一JSON增加 `public_review`。公共字段均是从逐题证据提炼的表达；不得另设一份评分。字段：

```json
{
  "public_review": {
    "subject": "英语",
    "brand": "上海高中一对一 · 英语学科组",
    "school": "真实学校",
    "exam": "真实学年、学期、年级、考试节点",
    "headline": "一句话概括考查特点",
    "verdict": "60字左右的整卷判断，不推断学生实际成绩",
    "module_notes": {"实际模块名称": "该模块的具体考查要求"},
    "focus": [
      {"title": "重点一", "text": "题号及具体提醒", "ids": ["1"]},
      {"title": "重点二", "text": "题号及具体提醒", "ids": ["2"]},
      {"title": "重点三", "text": "题号及具体提醒", "ids": ["3"]}
    ],
    "actions": ["学生可以执行的订正行动"],
    "card_action": "回看考点 → 按题订正 → 同类复测",
    "note": "星级为同年级结构预估，非实测得分率；题量不代表配分。",
    "source_label": "真实原卷来源及评价责任区分"
  }
}
```

模块题量、题号数和星级计数由 items 自动生成，不在公共字段手填；无法可靠评星的题目不展示星级，核验信息保留在教师底稿。脚本检查重点引用题号及模块集合，但文字是否准确仍需学科复核。不要把示例中的英语要求复制进数学或物理；card_action也按实际学科写。

## 排版与验收

教师版正文可用宋体，10.5pt左右；标题黑体。对外版中文正文优先宋体，标题可用清楚的黑体层级，主标题约23pt、正文10—11pt，避免复杂装饰。PDF元数据只使用有依据的作者信息，不加虚构署名、水印；保留真实原卷来源。

实际编译、检查页数/A4尺寸、提取正文，并查看最终PDF页面及PNG。逐页浏览成品，重点放大检查密集正文、原题摘录、句法图、选项和改动页；检查中英文字体及标点、题号/空格/原文/图/答案对应、缺字、重叠、裁切、跨页及手机阅读大小。不能把编译通过写成内容审校通过。Excel只改颜色时保留原公式及缓存，勿用重存方式清空公式缓存。检查三种呈现统计一致，明确独立复核覆盖范围。

## 学习建议

面向手机转发的宣传图优先使用单栏，保留卷名、整体判断、两三处带真实题号的分析及可执行学习建议；详细模块表放在完整快评中。可以用一句自然的后续行动引导联系老师，但不虚构联系方式或承诺效果。输出后缩至约 375 像素宽检查关键信息，并说明这不是实际手机或微信压缩后的测试。

对外快评PDF及简版图均增加一条“学习建议”，写入 public_review.learning_advice。建议应结合本卷考查特点，指出可练习的考点和同类题；频率和复测方式可按实际需要提供，不虚构个体学习计划；没有学生作答证据时，表述为一般学习建议，不冒充个体诊断。

## 多维快评与层次输入

完整报告执行 [analysis-dimensions.md](analysis-dimensions.md)，包含六个分析维度和三档讲评安排。指定层次时运行 `python3 scripts/publish_review.py 评价底稿.json 输出目录 --learner-level 基础巩固`，写入输出目录的“基础巩固”子目录；其余两档同理。没有层次输入时保留通用概览与三档教师安排，不替学生定档。题目星级保持不变。

## 合册结构

用户要求参考大同中学合册时，按整卷概览、试卷快评、考点分布、代表题讲解、学习建议、逐题明细组织，具体分页依内容决定。首页先介绍真实卷名、考试节点、题量和整卷判断；将重复的“关键判断”和“命题亮点”合并成一组带本卷题号的亮点，不在后页重复。

用带分隔线的表格呈现“实际题型或模块—作答项数量—考查内容与题号”，注明计数口径；阅读理解按小问计，篇章本身不另计。逐项评分可靠时优先制作难度图，评分不足时先查证，仍影响结论则询问用户，可按实际题型分组或分行，明确横轴题号和纵轴星级，保持原题号顺序，不强套数学选填／大题布局；听力、写作等影响结论的不可核验项向用户询问，不能画成零难度。题量与分值分开统计，不借用参考卷数据。

代表题讲解展示足以判断的真实原题、材料上下文、选项、答案及分步解析。引用原卷页码或题号，展示定位句、关键语义与干扰项区别；翻译和写作呈现题目约束与参考答案的适用边界。版面给题干、证据和解析留足行距；句法结构或语篇逻辑确能帮助理解时可配图并注明示意范围。避免只列抽象策略而无具体题证。选例按实际教学价值决定，勿机械排除压轴题。

学习建议面向本卷对应考点和同类题练习，不凭试卷推断学生错因或安排固定周期。教师底稿可保留分层讲评与题号，学生/家长版删去对读者无用的内部说明。现有出版脚本不保证自动生成该合册，应据内容排版并验收。

## 对外文风与星级

面向学生和家长直接写本卷事实、题号、考查方式和可执行建议，用自然的教师口吻，不写“本册不作推测”“数据待核”等过程说明或无信息量的套话。缺失指标直接省略；影响理解或答案正确性的实质疑点保留在教师底稿，必要时以简洁准确的方式提示。难度统一用五颗星呈现，实心星表示等级、空心星补足五颗，例如 ★★★☆☆；不得给尚无法评定的题目编造星级。

### 参考案例的信息结构

独立宣传长图可参考用户提供的考后快评案例：卷名和简明判断 → 已核实的题量、分值、时长与结构 → 题型及知识模块分布 → 具体题型或原题的亮点与易错点 → 对应考点的学习建议与自然行动引导。按实际证据取舍，长图保证手机阅读，完整题干与详解放在多页 PDF；需展示原题时保持可核对。案例中的比例、分值、学校、品牌和联系方式均不是模板数据，不得沿用或虚构。
