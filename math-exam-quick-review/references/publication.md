# 快评出版与受众投影（旧版参考）

> 当前交付以 [前端与教师后端通用框架](audience-framework.md) 为准；以下旧版内容仅供排版技术参考，与新版冲突时不执行。

## 默认交付

默认交付学生家长前端快评 PDF；教师讲评 PDF、PNG、Excel 和 Markdown 按用户要求从同一底稿生成。默认不制作网页，不交 Excel 截屏充当宣传图。

- **教师讲评 PDF**：A4，最上方必须有整卷说明，含来源、年级学期、题量、主要考查内容、结构难度、讲评顺序。正文“逐题评价 → 完整题目及原图 → 考点 → 答案 → 解析”，同题就地可读。长题与长解析允许续页，题头不孤悬。已有可靠解析则校核后复用，不能把答案摘要假装完整解析；缺解时先完成可靠快评，补解按学科流程核验，交付明确实际覆盖范围，不能标为完整讲评。不得为了固定页数缩小到难读。
- **整卷快评 PDF**：按内容组织页数；包含原题、图解或用户指定合册结构时可排多页。首屏先交代真实学校/考试节点与整卷判断，再列模块题量和主要要求、难度分布、带题号的三处重点、学生能执行的订正建议。少用内部术语。只有题量无分值时不能把题量占比写成分值占比。当前公共出版脚本限单页，超过一页会报错；需要多页时另行排版，不压字号蒙混过关，也不声称脚本已自动支持合册。
- **简版 PNG**：独立排版，通常1200px以上宽，白底或极浅底、学科色标题、清晰表格与短句，手机打开可读。保留整卷看点、模块概览、代表题号与行动提示。不得缩整本PDF或Excel成一张图。不默认加二维码、电话、虚构案例、合格线、优秀线或提分承诺。
- **教师 Excel/底稿**保留题号、星级依据、知识树定位、原卷疑点、核验范围；对外版本省去本机路径、OCR日志与技术流程，不隐瞒影响结论的实质疑点。未核题可以不做确定性宣传，必要时简短注明范围。

## 配色单一来源

读取 assets/subject-colors.json：accent 用于细线和强调，ink 用于彩色文字，tint 用于浅色底；正文深灰，表格浅灰细线，避免大面积饱和底色。颜色通过一份配置应用到PDF、PNG与Excel。当前语文红、数学绿、英语橙、化学紫、生物粉均为用户截图近似色，不是源代码精确值；物理为用户确认的浅蓝色，具体色值为视觉近似；取得准确色值后替换。不得把南京图里的数学蓝/英语紫误当用户当前配色。用户提供工作台色值时优先更新配置；深色正文需保持浅底可读。

## 可复用出版命令

依赖 Python 3、Typst、Poppler（pdfinfo/pdftoppm）；不含OCR与学科推理。脚本与配置随各科技能自包含，三份共用源一致，修改共用部分后同步。

```bash
python3 scripts/publish_review.py 评价底稿.json 输出目录
```

沿用 references/data-contract.md，在同一JSON增加 `public_review`。公共字段均是从逐题证据提炼的表达；不得另设一份评分。字段：

```json
{
  "public_review": {
    "subject": "英语",
    "brand": "上海高中一对一 · 英语学科组",
    "school": "真实学校",
    "exam": "真实学年、学期、年级、考试节点",
    "headline": "一句话概括考查特点",
    "verdict": "60字左右的整卷判断，不推断学生实际成绩",
    "module_notes": {"实际模块名称": "该模块的具体考查要求"},
    "focus": [
      {"title": "重点一", "text": "题号及具体提醒", "ids": ["1"]},
      {"title": "重点二", "text": "题号及具体提醒", "ids": ["2"]},
      {"title": "重点三", "text": "题号及具体提醒", "ids": ["3"]}
    ],
    "actions": ["学生可以执行的订正行动"],
    "card_action": "回看考点 → 按题订正 → 同类复测",
    "note": "星级为同年级结构预估，非实测得分率；题量不代表配分。",
    "source_label": "真实原卷来源及评价责任区分"
  }
}
```

脚本的模块计数按独立作答项统计，并非卷面大题数，表头必须标“作答项数”。正式合册的模块题数按卷面题号及主考点唯一归类，同一大题多个小问不得重复计数；如小问跨模块，采用明确的主模块归属并核对原卷。题号数和星级计数由 items 自动生成，不在公共字段手填；无法可靠评星的题目不展示星级，核验信息保留在教师底稿。脚本检查重点引用题号及模块集合，但文字是否准确仍需学科复核。不要把示例中的英语要求复制进数学或物理；card_action也按实际学科写。

## 排版与验收

教师版正文可用宋体，10.5pt左右；标题黑体。对外版正文优先宋体，标题可用清晰的黑体层级，主标题约23pt、正文10—11pt，避免复杂装饰。PDF元数据作者默认chengbai，不加可见签名或水印；保留真实原卷来源。

实际编译、检查页数/A4尺寸、提取正文，并查看最终PNG。抽查首页、密集正文页和改动涉及页；检查题号/空格/图/答案对应、缺字、裁切、跨页及手机阅读大小。不能把编译通过写成内容审校通过。Excel只改颜色时保留原公式及缓存，勿用重存方式清空公式缓存。检查三种呈现统计一致，明确独立复核覆盖范围。

## 学习建议

面向手机转发的宣传图优先使用单栏，保留卷名、整体判断、两三处带真实题号的分析及可执行学习建议；详细模块表放在完整快评中。可以用一句自然的后续行动引导联系老师，但不虚构联系方式或承诺效果。输出后缩至约 375 像素宽检查关键信息，并说明这不是实际手机或微信压缩后的测试。

对外快评PDF及简版图均增加一条“学习建议”，写入 public_review.learning_advice。建议应结合本卷考查特点，指出适合练习的考点与方向；可根据需要补充练习动作和复测方式；没有学生作答证据时，表述为一般学习建议，不冒充个体诊断。

## 多维快评与层次输入

完整报告执行 [analysis-dimensions.md](analysis-dimensions.md)，包含六个分析维度和三档讲评安排。指定层次时运行 `python3 scripts/publish_review.py 评价底稿.json 输出目录 --learner-level 基础巩固`，写入输出目录的“基础巩固”子目录；其余两档同理。没有层次输入时保留通用PDF与三档教师安排，不替学生定档。题目星级保持不变。

## 合册结构

用户要求参考大同中学合册时，按封面整卷概览与本卷亮点、01试卷快评、02考情分析、03学习建议、逐题明细附录组织。整卷亮点集中呈现一次，合并同义的关键判断和命题亮点；分别交代难度、结构与卡点、带题号的学习方向与分层讲评。缺失的数据不在对外版设置空指标，不借用参考卷的数据、分数档或结论；学生层次根据实际作答选择。此处是内容规则，现有出版脚本不保证自动生成该合册。

## 对外文风与星级

面向学生和家长直接写本卷事实、题号、考查方式和可执行建议，用自然的教师口吻，不写“本册不作推测”“数据待核”等过程说明或无信息量的套话。缺失指标直接省略；影响理解或答案正确性的实质疑点保留在教师底稿，必要时以简洁准确的方式提示。难度统一用五颗星呈现，实心星表示等级、空心星补足五颗，例如 ★★★☆☆；不得给尚无法评定的题目编造星级。


## 原题图解与考点结构

- 面向家长和学生的代表题讲解要附可核对的完整真实原题和必要原图，再说明考点、关键条件、方法、答案和解析；整卷分析中的判断也要由真实题号及具体条件或转化支撑，不用脱离题目的泛泛表述。题面、图与解析一一对应；题目过长允许跨页，不为压缩页数牺牲字号。
- 对参数最值、区间端点、函数图像等题目，图确能帮助理解时，绘制数轴或示意图，将可行范围、关键点、端点取舍和等号情形与文字推导对应。图注明示意、非等比例等适用边界；不画成与条件矛盾的几何关系。
- 对抽象证明，将关键推理分步说明；如果用反证假设画图，明确标为假设情形，区分函数、辅助直线和界，图不替代证明。需要反例时注明满足哪些条件、违反哪个结论。
- 考点分布用清晰分隔的表格展示“模块｜题数｜具体考查内容与原卷题号”；注明题数按大题的主要考点唯一归类，多个具体节点不重复计数，不把题数当分值。按实际试卷确定模块：数列独立，三角函数与解三角形合并，平面向量独立，圆及圆锥曲线归解析几何；不强行给未考模块填数据。
- 对外快评详细讲解 1—2 道亮点题，以中档题为主，兼顾本卷代表性、可读性及讲解价值；其他题可在整卷亮点、逐题统计中简述。例题以易理解、有代表性和适合图解为准；选填压轴题可入选，须按题目本身的推理评估，不能仅按题号判难。学习建议围绕本卷考点指出适合练习的方向；无学生作答证据不声称个人弱项，不强制安排具体频次。

## 难度图与布局

- 难度数据从逐题评价底稿生成，与 Excel 共用星级口径；未知难度不填造。上排排列选填题，下排排列解答题的各小问；横轴明确题号，纵轴标注 1—5 级结构难度。题目过多时分图或分页，保证题号清楚，不强行压缩；此图是结构预估，不称实测难度。
- 代表题解析按思路分段，关键推导独立成行并留足行距；图只在能说明条件、范围、转折或证明关系时加入，图上标注和正文对应，不能只为装饰画图。重点公式与图形不得挤在窄卡片里；两种答案或分数坐标可分行并留足间距。
- 检查整卷亮点、分析、附录各司其职；去除无新增信息的重复宣传段落。正文用自然、具体的教师语言，不用空泛术语堆砌。

## 数学公式验收

- 数学公式及图内标注使用可靠的数学排版引擎（如 Typst、LaTeX、KaTeX），中文正文按既定宋体风格；避免把公式作为普通文本或借 Unicode 字符拼接替代数学排版。分数、根号、上下标、导数撇号、不等号及区间端点均须正确清楚。
- 图片导入 PDF 时核对数学字体是否嵌入或已安全转为矢量轮廓；同时检查图中标注与正文的变量、条件、等号和坐标一致。预览最终 PDF 的公式密集页、图解页和原题截图，放大核查缺字、错位、裁切和手机阅读大小；编译通过或文本提取成功不代表公式显示正确。同时检查导数撇号与括号、图中曲线与公式标签是否重叠，检查坐标内各分数、上下标和行间距离；必要时把公式移到图外，或将候选答案分行。发现问题则修复并重编、复查受影响页面。
- 现有公共出版脚本不自动实现上述图解或公式修复；应根据本卷编辑、排版并验证，不声称脚本已覆盖。

## 最终交付与版面检查

单页脚本仅为摘要排版辅助：其输出不含逐题难度柱状图、模块考点结构表、真实原题与详解，不能直接视为符合要求的多页完整快评或教师讲评。另行制作所需合册，并核对题目、图表、Excel 与底稿一致。宣传图和对外 PDF 必须保留结合本卷考点的学习建议；缺少关键证据时先查证，仍不能确定则询问用户，不补造题干或解析。

逐页实际预览 PDF 和 PNG：检查公式、图中文字、换行与截断；正文保持易读字号，减少过密段落和明显不均衡的大片留白。代表题按教学价值与理解门槛选择，必要时用图解释推理；不以题号判定难度。教师版区分已复核的解析与引用的原解析，未核验的内容标明范围。

### 参考案例的信息结构

独立宣传长图可参考用户提供的考后快评案例：卷名和简明判断 → 已核实的题量、分值、时长与结构 → 题型及知识模块分布 → 具体题型或原题的亮点与易错点 → 对应考点的学习建议与自然行动引导。按实际证据取舍，长图保证手机阅读，完整题干与详解放在多页 PDF；需展示原题时保持可核对。案例中的比例、分值、学校、品牌和联系方式均不是模板数据，不得沿用或虚构。
