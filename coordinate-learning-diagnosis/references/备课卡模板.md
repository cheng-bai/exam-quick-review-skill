# 下节课备课卡

按任务填写，不把空白模板原样交付。已有教师版结构时把相应内容放入原位置，不重复抄写。

主题：具体知识点；模式：备课预判／课后诊断／复测复盘。
来源：原题文件或材料名、题号、可用页码或时间戳。
个人记录才填写学生代号和实际日期；未知写未知。备课预判不需要虚构学生。

| 项目 | 内容要求 |
|---|---|
| 本课先解决什么 | 1–2 个具体问题；预判时写“本课先检查是否……” |
| 根据什么判断 | 实际写法、原话及证据编号；预判时写“题目要求的关键步骤，尚无学生证据” |
| 学生已经会什么、卡在哪里 | 只记已证实表现；预判写“上课待确认” |
| 核心知识与目标 | 讲清什么道理或条件；从哪一步练到哪一步，附必要层级对照 |
| 先问什么 | 一句能区分原因的问题，预期回答和不同回答后的处理 |
| 用哪道题讲 | 题目来源/编号及完整题目、答案或关键步骤、选它的理由 |
| 老师怎么帮 | 可直接使用的提问、学生动作、卡住时的小提示、何时撤提示 |
| 接着练什么 | 每题完整题目、答案、用途；不只写“做同类题” |
| 怎样算过关 | 明确正确性、理由解释、是否独立；说明时间条件 |
| 下次课怎么查 | 复习前用哪一道相近要求的新题、答案与通过标准；尚未做写“待测” |
| 不符合预期怎么办 | 是补问、换讲法还是排查新知识；不能只写“加强练习” |

卡后简注：诊断模式写主码、辅码及其依据，必要时写“主码待定”；标出知识维度、已达与目标层级。备课预判只写“若出现……，先检查……”，不做个人定型。

各题可以通过一次列出后引用编号来避免重复，但交付物须能直接找到题目、答案和标准，不依赖模糊的“上一道题”。本课最后的无提示小题与下次课复测分开记录。

复测后只补充真实发生的内容：

| 日期与题号 | 独立/提示后/模仿完成 | 实际步骤或原话 | 对原判断的影响 | 下次安排 |
|---|---|---|---|---|

未实施时不填虚构结果。已支持的原因可以保留，新证据相反时撤回或调整判断；一次做对不推断所有同类题都已掌握。
