# 坐标教学法：看清卡点，再决定怎么教

同样考 90 分，有人是不懂概念，有人是计算不稳，也有人会做基础题，却不知道综合题从哪里开始。他们需要的帮助不同。这就是“分数是标量，学情是向量”想表达的意思：除了得了多少分，还要看学生具体会什么、哪里不会、为什么不会。

这套方法按四步使用：

1. 看学生怎么做、怎么说，找出卡住的地方。
2. 判断眼下最需要补什么、练什么。
3. 围绕同一个知识点，选适合这个学生的讲法。
4. 换题再试，检查有没有学会，决定下一步怎么教。

默认用于数学一对一教学。用于其他学科时，把数学概念换成对应学科的知识。以下例子只说明方法，不能当成真实学生的表现。

## 先选入口：这次是在备课，还是已经看到了学生表现

| 手头材料与任务 | 这次做什么 | 结论边界 |
|---|---|---|
| 只有题目、解析或通用讲义，需要备课 | 找关键步骤，预想可能卡点，准备探查问题和条件式讲法 | 标明“备课预判”；不填写某个学生的主辅码、类型或已达层级 |
| 有学生作答、草稿或课堂原话，需要复盘 | 对照具体步骤，判断原因，安排下一堂课 | 证据符合相应码的要求才暂定编码；不是有一份草稿就一定能定型 |
| 有上次记录和新练习结果 | 比较前后表现，决定继续练、换讲法或调整判断 | 区分独立、提示后、模仿完成；未做的复测仍写“待测” |

只有分数或印象，却要求诊断具体学生时，仍须追问证据。已有题目且任务是备课时，可以直接预判，不必等待学生材料。混合任务中把“可能发生”与“实际发生”分开写。

默认产出一张“下节课备课卡”，日常只选 1–2 个主要问题。用户要求完整诊断报告时，再用文末五模块展开。卡片格式见 [下节课备课卡](references/备课卡模板.md)；需要对照整套流程或说明两个学生怎样教时，读 [同题不同讲法示例](references/同题不同讲法示例.md)。

## 第一步：先看具体表现，再判断原因

### 要看哪些材料

优先看原题、学生的答案和草稿，以及学生解释“我是怎么想的”的原话。已知的话，再记下是否限时、老师有没有提示。给材料标上 E1、E2 等编号，方便后面说明判断依据。

把“看见的表现”和“对原因的猜测”分开。例如：

- 看见的表现：学生把 `2(x-3)` 写成了 `2x-3`。
- 学生的解释：“括号外面的 2 只乘 x。”
- 根据这些材料，暂时判断：学生可能没有理解分配律。

只有错误答案，还不能确定是没理解，还是这次漏乘了。教师转述要注明“教师转述”，看不清的字或缺失的题目条件要标明，不猜填。

如果只有“考了 90 分”“基础差”“总是粗心”，先问：

> 请提供一道错题的草稿，或学生解释自己怎么做的原话；有了这些，才能判断问题出在哪里。

一次先问最关键的一件事。诊断材料不足时，暂停学生定型；若已有题目，可以先给明确标为“备课预判”的探查任务，不编造学生表现。

### 先对照解题步骤，找到第一处真正卡住的地方

核对题目条件、答案和关键解法后，列出完成任务需要的少量关键步骤。已有题素分析时复用其关键转换；题目难度只帮助选题，不能证明某个学生会不会。

按“题目需要做什么 → 学生实际做了什么 → 第一处阻断解题的错误或缺口”对照。先检查学生自己的方法是否成立，允许与参考解法不同；简写也不一定是漏懂。区分最初错误和它带来的后续错误，不重复定型。

例如求函数单调区间，可以分别检查求导、判断导数符号、结合定义域写区间；不能把三步都笼统写成“导数不会”。只记录有证据的步骤，空白处写“尚不清楚”，再用一个小问题探查。

课堂转录要注明是谁说的，并保留可用的时间戳、页码或题号。老师讲过不等于学生理解；跟着老师说对不等于能独立做对。说话人无法确认时标注待核对，不把教师的话当作学生证据。

### 用五个字母记下原因（KSTHP）

| 记号 | 白话解释 | 要看什么才能这样判断 |
|---|---|---|
| K：知识没弄懂 | 概念、公式或使用条件理解有误 | 让学生解释“为什么能这样做”，发现解释本身就错了 |
| S：操作不稳定 | 知道道理和做法，但运算或变形出错 | 已有正确解释或独立操作的表现，错误出在具体执行中；不能只凭一句“我会” |
| T：不知道怎么入手 | 基础知识和操作会，但不会选方法、连步骤 | 单独的小问题能做，放在综合题里就不知道先做什么；先排查是否有知识没弄懂 |
| H：做题习惯反复出问题 | 经常跳过关键步骤、草稿难以核对、做完不检查 | 多道题或多次课堂里反复出现；只漏写一次，不能直接这样判断 |
| P：紧张或畏难影响发挥 | 有能力做，却因害怕出错、时间压力等难以发挥 | 结合学生原话，比较有压力和无压力时的表现；空白、慢答不能单独证明这一点 |

不要用“粗心”结束分析。继续看：到底是哪一步错了？是操作不稳（S），还是某个做题习惯反复带来错误（H）？也可能是知识理解有误（K）。

这些字母用于安排教学。尤其是 P，只描述当前做题时可能存在的压力影响，不代表心理疾病。

### 先解决哪个问题

- **主码**：这次最先要解决的问题。它最直接地卡住了学生，不一定是错误最多的一项。
- **辅码**：同时存在、也需要照顾的问题。没有证据就写“暂未发现”，不用凑。
- 分不清时写“还不能确定”，再安排一个小任务来区分。例如，让学生解释分配律，再独立展开一个新式子。

每个判断都要说清：“根据 E1 的哪一步和 E2 的哪句话，我暂时判断……；还需要确认……”。

如需填写原框架的类型名称，对应为：K 知识断层型、S 技能不稳型、T 策略匮乏型、H 习惯失范型、P 心理抑制型。只说“这个知识点上暂时表现为……”，不要把它写成学生一直如此的标签。

### 把“坐标定位”说具体

坐标定位就是记清：在什么知识点上，学生已经能做到哪一步，又卡在哪一步。

先说明学的是什么：

| 原术语 | 白话解释 |
|---|---|
| 事实性知识 | 概念、性质、公式本身，例如“分配律是什么” |
| 方法性知识 | 做题步骤和常用方法，例如“怎样解一元一次方程” |
| 思想性知识 | 面对问题时的大思路，例如“把复杂问题拆成已会的小问题” |

再说明学生能做到什么：

| 层级 | 看得见的表现 |
|---|---|
| 记忆 | 能说出或写出公式、定义 |
| 理解 | 能解释为什么这样做、什么时候能用 |
| 操作 | 能按方法把题做出来 |
| 识别 | 能从题目条件中判断该用什么方法 |
| 迁移 | 换一种问法或情境，仍能用上所学方法 |
| 综合 | 能把多个知识点和方法连起来解决问题 |

这两张表帮助描述表现，不用于给学生机械打等级。会做一道难题，不代表所有知识都已掌握。

写成三句话即可：“已经能独立……；目前卡在……；这次先练到……”。不知道的部分写“尚未确认”。老师提醒后做对、照着例题做对、完全独立做对，要分开记录。

## 第二步：根据原因，决定怎么帮

| 主要问题 | 教学方向 | 老师具体做什么 |
|---|---|---|
| K：没弄懂 | 补 | 从不懂的概念或条件讲起，用具体例子说明，再回到公式 |
| S：做不稳 | 稳 | 请学生边做边说每一步，找出容易出错的操作，集中练这一小步；先做对，再适当限时 |
| T：不会入手 | 拓 | 教学生看什么条件、为什么选这个方法，再比较不同做法 |
| H：习惯反复出问题 | 规 | 针对实际错误，约定少量明确动作，例如“去括号写全一行”“答案代回检查” |
| P：压力影响发挥 | 疏 | 从学生能独立完成的小任务开始，逐步增加难度和时间要求，帮助恢复把握感 |

先围绕主码安排教学，有辅码时再补上相关做法。原因还没弄清，先用小任务了解情况。

对紧张的学生，先看不限时能做到什么，再根据其表现和反馈逐步加入计时；若明显更紧张，就退回较容易完成的安排。

## 第三步：知识讲准确，讲法因人调整（一核多径）

“一核”就是这次必须讲清的知识和道理；“多径”就是可以用不同方式帮学生学会。换讲法时，公式的使用条件、数学道理不能变。

例如，教 `2(x-3)` 时，要讲清：括号外的 2 要乘括号里的每一项，所以结果是 `2x-6`。围绕这个道理，可以这样教：

| 适合的情况 | 具体讲法 | 原路径名称 |
|---|---|---|
| 没理解，或需要从容易的任务开始 | 先写成 `(x-3)+(x-3)`，请学生合并，再说明与分配律的关系 | 直观建构径 |
| 懂道理，但执行不稳 | 给“逐项相乘 → 看清符号 → 合并”的框架，让学生自己填步骤，并说出每个乘积 | 通法固化径 |
| 会基本操作，但不会选方法 | 用合适的综合题，问“这些条件能让你想到什么方法？为什么先做这一步？”比较方法适用的条件 | 思想方法径 |
| 反复因跳步或不检查出错 | 在主要讲法上加 2–3 个检查动作，例如圈出每一项，检查是否都乘到了 | 规范强化径 |

选最适合的一种主要讲法即可；规范练习可以同时加上。起点要依据学生已有表现，不因一个字母就固定教学难度。

每次方案写清六件事：

1. **这次讲清什么**：用一两句话说明知识、道理和使用条件。
2. **从哪里开始，到哪里结束**：例如“从解释每一项为什么都要乘，练到独立展开新式子”（理解 → 操作）。
3. **老师怎么问**：写出能直接在课堂使用的问题。
4. **学生做什么**：写出希望学生说出的解释、写出的步骤。
5. **不会时怎么提示**：先给一个小提示；下一题减少或去掉提示。
6. **怎样算学会这一步**：例如“没有提示，能正确展开新式子，并解释每一项的来源”。

完整教学方案至少给一道具体例题和一道针对同一问题的变式，写出答案或关键步骤，并核对是否正确。只做原因探查或局部复盘时，按任务需要给题，不强行补全整课。优先用学生原题；另编的示例须注明“教学示例，不是学生实际作答”。

一个简短示范：若学生的写法和解释都显示他误解了分配律，可先教 `2(x-3)=8`，正确展开后解得 `x=7`；再让他独立做 `3(x-2)=12`，答案为 `x=6`。重点看去括号是否正确，以及能否解释原因，不只看最后答案。

### 每道变式先说明拿来做什么

可选用途是：分辨原因、集中练某一步、检查独立完成、下次课复测。一题可以兼顾多项，不机械要求四题。每题保留题目来源或编号、完整题目、答案或关键步骤、检查目标、提示与时间条件；自编题注明“自编”。尽量先复用已核对的题，再改编。

选题从当前卡点出发，不只按简单、中等、困难分配。提示后完成的题可以作为练习结果，不能充当无提示过关证据。

## 第四步：换题再试，看看是不是真的学会了

这一步就是“重测与向量校准”：拿新的作答和之前比较，看原来的问题有没有改善，再决定继续练、换讲法，还是重新判断原因。

可安排当堂做一次、下次课再做一次。通常用 3–5 个小任务，按实际需要合并：

- 专门检查刚才卡住的那一步。
- 检查近期学过的内容还会不会。
- 换数字、问法或情境，看能否自己用上方法。
- 做题时顺便观察：还需几次提示？会不会主动检查？学生怎样描述自己的紧张程度？

每道题都写明题目、答案、检查什么、是否提示或计时，以及怎样算通过。还没做的检测写“待测”，不能写成已经进步。

例如，学完上述分配律后，可用：

| 时间 | 小任务与答案 | 重点看什么 |
|---|---|---|
| 当堂 | 展开 `4(y-2)`，答案 `4y-8` | 无提示时，两项是否都乘到了 |
| 当堂 | 判断 `3(t-1)=3t-1` 是否正确，并解释；应为 `3t-3` | 能否指出漏乘，并说清理由 |
| 下次课，复习前 | 解 `3(x-4)=9`，答案 `x=7` | 隔一段时间后，仍能独立展开并解答 |

这组示例先不限时；如果实际问题与时间有关，另作安排并记录。通过标准可以写成“前两题独立做对且能解释，第三题下次课独立做对”，不能只写“基本掌握”。

比较前后表现时，尽量使用相近难度和提示条件。新题如果加入负数或其他新要求，出错后要分清是原问题没解决，还是新内容不会。

用四句话记录：“原来……；希望这次能……；实际看到……；下一步……”。不要只用总分变化下结论。

- **改善不明显**：检查讲法是否合适、练习有没有落实、题量和质量是否足够，也看看新题是不是更难了；不直接归结为不努力。
- **表现与原判断不一致**：例如原以为只是算错，重测却发现公式意义没懂，回到第一步重新判断主码和辅码。
- **已经能独立完成**：减少提示，或增加一点变化，下次课再确认是否保持。

## 与已有讲义和资料流程衔接

- 教师版母题已有“选题原因、错因预设、讲法建议”时，在这些位置补上本次内容，不再重复附一份同义长报告。“错因预设”只写可能问题和探查问句。
- 学生个人作答、诊断和复测结果单独保存在教学任务目录，保留日期、学生代号、题号、来源位置、提示条件和前次记录引用。缺失信息写未知，不猜日期或身份。不放进 skill 文件夹，不混入通用讲义或学生版。
- 默认交接备课卡和必要练习即可。用户要求文件时，用中文语义化文件名，例如“函数单调性-下节课备课卡.md”；保留源材料和既有记录，新观察按日期追加或创建新副本，不覆盖旧结论。
- OCR、答案审校、题素分析、变式生成和 PDF 排版按任务需要交给现有对应技能，本技能负责把学生表现转成教学决定。不因一次诊断自动启动整套流水线、修改其他技能、建立长期记忆或发送学生资料。
- 交给讲义或变式流程时，传递已有证据、暂定码或未定原因、具体教学目标、题目用途和通过标准，要求保留这些依据；不要让下游仅凭类型名重新猜诊断。

## 给教师的输出格式

默认使用上述备课卡，预判模式不要求学生证据与个体定型。需要完整诊断且材料足够时，保留以下五个模块。每个模块先用白话说结论，术语放在括号里作对照，不用术语代替解释。

### 【学情证据分析】学生具体怎么做、怎么说

列出材料编号、原始写法或原话、已知的提示与时间条件。缺什么就注明什么。

### 【KSTHP编码与定型】这次主要卡在哪里

说明主码、辅码及依据，类型只作当前判断。再写：“已经能独立……；卡在……；这次目标是……”，附相应知识维度和能力层级。

### 【因型择向】眼下先怎么帮

说明这次以补、稳、拓、规、疏中的哪一个为主，以及为什么。

### 【一核多径讲解路径设计】这堂课具体怎么讲

写清核心知识、起点和目标、选用讲法、例题与变式、师生对话、提示如何减少，以及达标表现。

### 【定期重测与向量校准建议】怎样确认学会，没学会怎么办

列出小测任务、答案和通过标准、检测时间及观察事项，再写没有改善或判断不符时怎样调整。

如果个体诊断材料不足，先问关键问题，不为填满五个模块猜测学生情况。备课预判可以继续，但明确是假设。用户只需要其中一部分时，就回答那部分。
