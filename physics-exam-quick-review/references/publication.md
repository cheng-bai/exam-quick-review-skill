# 快评出版与受众投影（旧版参考）

> 当前交付以 [前端与教师后端通用框架](audience-framework.md) 为准；以下旧版内容仅供排版技术参考，与新版冲突时不执行。

## 默认交付

默认交付学生家长前端快评 PDF；教师讲评 PDF、PNG、Excel 和 Markdown 按用户要求从同一底稿生成。默认不制作网页，不交 Excel 截屏充当宣传图。

- **教师讲评 PDF**：A4，最上方必须有整卷说明，含来源、年级学期、题量、主要考查内容、结构难度、讲评顺序。正文“逐题评价 → 完整题目及原图 → 考点 → 答案 → 解析”，同题就地可读。长题与长解析允许续页，题头不孤悬。已有可靠解析则校核后复用，不能把答案摘要假装完整解析；缺解时先完成可靠快评，补解按学科流程核验，交付明确实际覆盖范围，不能标为完整讲评。不得为了固定页数缩小到难读。
- **整卷快评 PDF**：按内容安排页数，整卷说明、考点及示例题解保持清晰可读。首页先交代真实学校/考试节点与整卷判断，再以适当篇幅呈现模块覆盖、难度分布、带题号的亮点及学习建议；题证与解析可另页展开。少用内部术语。只有题量无分值时不能把题量占比写成分值占比。当前脚本限单页，超过一页会报错；需按语义删冗余或显式设计双页模板，不压字号蒙混过关。
- **简版 PNG**：独立排版，通常1200px以上宽，白底或极浅底、学科色标题、清晰表格与短句，手机打开可读。保留整卷看点、模块概览、代表题号与行动提示。不得缩整本PDF或Excel成一张图。不默认加二维码、电话、虚构案例、合格线、优秀线或提分承诺。
- **教师 Excel/底稿**保留题号、星级依据、知识树定位、原卷疑点、核验范围；对外版本省去本机路径、OCR日志与技术流程，不隐瞒影响结论的实质疑点。未核题可以不做确定性宣传，必要时简短注明范围。

## 配色单一来源

读取 assets/subject-colors.json：accent 用于细线和强调，ink 用于彩色文字，tint 用于浅色底；正文深灰，表格浅灰细线，避免大面积饱和底色。颜色通过一份配置应用到PDF、PNG与Excel。当前语文红、数学绿、英语橙、化学紫、生物粉均为用户截图近似色，不是源代码精确值；物理为用户确认的浅蓝色，具体色值为视觉近似；取得准确色值后替换。不得把南京图里的数学蓝/英语紫误当用户当前配色。用户提供工作台色值时优先更新配置；深色正文需保持浅底可读。

## 可复用出版命令

依赖 Python 3、Typst、Poppler（pdfinfo/pdftoppm）；不含OCR与学科推理。脚本仅产单页概览 PDF、独立简图及统计，不生成教师 PDF、完整多页题证快评或 Excel。

```bash
python3 scripts/publish_review.py 评价底稿.json 输出目录
```

沿用 references/data-contract.md，在同一JSON增加 `public_review`。公共字段均是从逐题证据提炼的表达；不得另设一份评分。字段：

```json
{
  "public_review": {
    "subject": "物理",
    "brand": "上海高中一对一 · 物理学科组",
    "school": "真实学校",
    "exam": "真实学年、学期、年级、考试节点",
    "headline": "一句话概括考查特点",
    "verdict": "60字左右的整卷判断，不推断学生实际成绩",
    "module_notes": {"实际模块名称": "该模块的具体考查要求"},
    "focus": [
      {"title": "重点一", "text": "题号及具体提醒", "ids": ["1"]},
      {"title": "重点二", "text": "题号及具体提醒", "ids": ["2"]},
      {"title": "重点三", "text": "题号及具体提醒", "ids": ["3"]}
    ],
    "actions": ["学生可以执行的订正行动"],
    "card_action": "回看考点 → 按题订正 → 同类复测",
    "note": "星级为同年级结构预估，非实测得分率；题量不代表配分。",
    "source_label": "真实原卷来源及评价责任区分"
  }
}
```

模块作答项数和星级计数由 items 自动生成，不在公共字段手填；无法可靠评星的题目不展示星级，核验信息保留在教师底稿。脚本检查重点引用题号及模块集合，但文字是否准确仍需学科复核。示例字段只演示结构；内容必须来自本卷。模块计数是 items 数，即独立作答项数，不是卷面大题数；脚本不推算卷面大题数；需要展示时按原卷人工核实，并注明统计口径。

## 排版与验收

教师版正文可用宋体，10.5pt左右；标题黑体。对外版中文正文优先宋体，标题可用清楚的黑体层级，主标题约23pt、正文10—11pt，避免复杂装饰。PDF元数据作者默认chengbai，不加可见签名或水印；保留真实原卷来源。

实际编译、检查页数/A4尺寸、提取正文，并查看最终PNG。抽查首页、密集正文页和改动涉及页；检查题号/空格/图/答案对应、缺字、裁切、跨页及手机阅读大小。不能把编译通过写成内容审校通过。Excel只改颜色时保留原公式及缓存，勿用重存方式清空公式缓存。检查三种呈现统计一致，明确独立复核覆盖范围。

## 学习建议

面向手机转发的宣传图优先使用单栏，保留卷名、整体判断、两三处带真实题号的分析及可执行学习建议；详细模块表放在完整快评中。可以用一句自然的后续行动引导联系老师，但不虚构联系方式或承诺效果。输出后缩至约 375 像素宽检查关键信息，并说明这不是实际手机或微信压缩后的测试。

对外快评PDF及简版图均增加一条“学习建议”，写入 public_review.learning_advice。建议应结合本卷考查特点，给出可延伸到同考点和同类题的练习方向；有依据时可补充具体动作或复测方式，不强定频率。没有学生作答证据时，表述为一般学习建议，不冒充个体诊断。

## 多维快评与层次输入

完整报告执行 [analysis-dimensions.md](analysis-dimensions.md)，包含六个分析维度和三档讲评安排。指定层次时运行 `python3 scripts/publish_review.py 评价底稿.json 输出目录 --learner-level 基础巩固`，写入输出目录的“基础巩固”子目录；其余两档同理。没有层次输入时保留通用PDF与三档教师安排，不替学生定档。题目星级保持不变。

## 合册结构

用户要求参考大同中学合册时，参照封面整卷概览、01试卷快评、02考情分析、03学习建议、逐题明细附录组织；首页亮点与正文命题亮点如表达相同意思，合并去重。分别交代难度与亮点、结构与卡点、带题号的学习主线与分层复测；学习建议围绕本卷考点，不强制安排固定周期。缺失的数据不在对外版设置空指标，不借用参考卷的数据、分数档或结论；学生层次根据实际作答选择。此处是内容规则，现有出版脚本不保证自动生成该合册。

## 对外文风与星级

面向学生和家长直接写本卷事实、题号、考查方式和可执行建议，用自然的教师口吻，不写“本册不作推测”“数据待核”等过程说明或无信息量的套话。缺失指标直接省略；影响理解或答案正确性的实质疑点保留在教师底稿，必要时以简洁准确的方式提示。难度统一用五颗星呈现，实心星表示等级、空心星补足五颗，例如 ★★★☆☆；不得给尚无法评定的题目编造星级。

## 原题证据、图解和物理表达

- **选题与证据**：将卷面判断落到真实题号和题目条件，挑选适合学生或家长理解的典型题。展示完整原题或清晰原题裁图（含必要选项、图形、坐标及条件），紧接考点、答案、分步解析；共用题干不可截断。原题与解析一一对应，图题缺失先回查原卷。教师底稿保留出处及原卷疑点；对外只提示影响理解或正确性的疑点。
- **解释而非堆字**：从研究对象、模型条件、过程阶段、关键规律和结论依次展开；物理量定义、正方向、适用条件、代入及单位写清楚。长式单独成行，必要时分步换行；图能帮助理解时绘制清晰的受力图、运动过程图、实验装置图或坐标图，在文字中说明图如何支撑关键推理。示意图标明方向、条件和是否按比例，不能把推测的结构画成原题事实。
- **难度与考点呈现**：逐题难度图按实际题型分组或分行（如选择填空与实验计算），解答题按可靠的独立小问展示；横轴标题号，纵轴标结构难度及等级，标明是估计而非得分率。不可判定的题先查证，仍不能确定则询问用户，不能画成零星；题数太多时分页或分组，不能压小到难读。考点覆盖使用有分隔的表格或清晰结构图，展示物理模块、具体考查内容、原题号及题数；说明大题或小问统计口径，不把题数当分值，各模块按题目实际主考点归类。
- **公式与版面检查**：中文正文优先宋体；公式用真正的数学排版，检查上、下标、分数、矢量箭头、角标、正负号、希腊字母、单位与图线之间的间距和遮挡；不要把 LaTeX 源码、错位普通文本或乱码直接交给读者。原题图保持清晰可辨；图例、坐标和公式标签不覆盖曲线或题干。编译后逐页查看实际 PDF，尤其是公式密集页、图示页和附录；核对原题、数字、符号与文字结论一致，修复裁切、过小、跨栏及重叠后重新编译并复看。图和表必须有可辨读标题、题号及必要图注。
- **区分工具能力和验收结论**：现有自动出版脚本是单页通用快评，不自动生成完整原题图解合册或验证物理公式；如需多页和题证，使用适当的专业排版流程另行制作，复用同一底稿。编译、文本抽取、视觉检查与物理正确性复核分别记录，不能仅凭编译成功宣称全部通过。

### 参考案例的信息结构

独立宣传长图可参考用户提供的考后快评案例：卷名和简明判断 → 已核实的题量、分值、时长与结构 → 题型及知识模块分布 → 具体题型或原题的亮点与易错点 → 对应考点的学习建议与自然行动引导。按实际证据取舍，长图保证手机阅读，完整题干与详解放在多页 PDF；需展示原题时保持可核对。案例中的比例、分值、学校、品牌和联系方式均不是模板数据，不得沿用或虚构。
