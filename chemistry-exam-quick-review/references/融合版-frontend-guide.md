# 前端快评制作规则

## 执行顺序与提速

- 先检查试卷是否已有同卷解析版或 Markdown、PDF 是否有可用文字层，以及环境中的字体和 PDF 排版工具。能提取的页面直接提取，只有图像页或识别有缺陷的页面才局部 OCR；不要对同一批页面反复全卷识别。
- 先一次性盘点影响交付的学科、题目、答案、总分和逐题分值等关键缺口，汇总具体问题询问；等待答复时继续处理不依赖缺失信息的部分。
- 只读取对应学科规则与需要的知识图谱节点，不必逐个打开其他学科资料。建立并核对一份底表，供热力图和逐题表共用，避免重复录入。
- 排版优先沿用已通过样张对照的本地模板；若环境已有 Typst，可从[版式起点](../assets/版式起点.typ)出发。该文件是需编辑的骨架，不是自动生成器：替换所有示例文字和颜色，按真实底表制作带色阶的热力图与完整连续表；检查字体、数学公式和分页，绝不将示例作为成品。没有 Typst 时用现有合适工具制作，不必强制安装。

## 一、先弄清的信息

- 试卷能明确识别学科、学校、年级、考试名称和时间时，直接采用；关键信息缺失或互相矛盾时先查看原卷、答案和附件，再问使用者。
- 从原卷或可靠配分表核实总分和每题分值。找不到、看不清或存在冲突时，明确问使用者提供分值或指定采用的配分标准。得到授权后可以按指定标准估配，并清楚识别这是一套约定配分；不能把估配写成原卷配分。总分与逐题分值需要核对一致。
- 答案或题目有影响结论的疑点，先检查解析、原图和推理；仍不能确定时问使用者。不要编造，不用“待核”“—”绕过关键问题。考点与难度属于专业判断，有题目证据时直接判断。
- 参考分数有依据时给出“合格参考 / 优秀参考”，明确它们是教学估计，不冒充学校分数线。若缺少形成估计所需的总分或使用者要求按某一既定标准但标准未知，应先询问。不要把未经证实的分数线当事实。
- 用户要求的配色优先。语文、数学、英语、物理、化学、生物按色卡中的学科色使用；物理为用户确认的浅蓝色，当前色值为近似值。如使用者提供工作台精确色值则采用精确色值。

## 版本、难度与考点的核对

- 复用同卷解析或 Markdown 前，比较卷头、前两题及末题关键条件；有矛盾时继续核查原卷，不凭文件名认定同卷。
- 分值参考按年份、考次和卷本匹配。原卷及同卷评分说明优先；不能将其他卷配分当作本卷事实，也不把大题分数均摊给小问，或根据总分反推缺失配分。用户明确指定配分标准后，方可按其约定处理。
- 难度以该卷对应年级学生为参照，根据知识点连接、方法选择、关键转化和论证层次判断；记录对应题号及理由，不仅以题号靠后判难。星级是专业判断，不是实测得分率。
- 知识图谱仅辅助统一名称；内部底表保留实际节点及来源，区分直接对应和相近节点，不把邻近节点写成精确命中。
- 可在内部底表暂留未知值以继续独立工作；关键答案、总分或所需逐题分值仍无法确认时，提出具体问题，确认后才能交付完整前端 PDF，不向家长输出“待核”。

## 二、前端 PDF 的内容与顺序

1. **标题与整体评估**：顶部为学科色块“［教学快评］机构名称”；标题格式为“年份 · 学校 · 年级学期 · 学科考试快评”，以原卷信息和使用者品牌要求为准；机构名称由使用者提供并同步替换所有品牌文字。展示整体难度（五颗星，已评部分实心、其余空心）以及合格、优秀参考分。用学科深色标签“一句话亮点”搭配右侧白底描边框，概括这套卷子的一个真实特点。
2. **考点分布**：一级标题以学科色小方块开头，使用“考点分布”。以带边框的热力图展示模块及具体考点和题号，色深和数量含义明确。一个小题涉及多个模块时，先确定唯一主归属以统计题数，其他关联考点可在文字中补充，避免重复计数；统计口径与逐题表一致。标题加粗，保留适当留白。
3. **逐题快评**：一级标题采用小方块和四字标题“逐题快评”。表格顶部以深色通栏写“机构名称＋试卷名称＋快评”，与列头紧连。列为“题型、题号、模块／考点、难度、分值、答案摘要”。难度均为五星制实心与空心星号。开放题概括答案要点，不凭空简化成唯一答案。

表格是连续的一张表，不按题型机械拆成多张，也不为凑页数把行挤得难读。必要时按自然分页续排，续页重复列头；跨页时不能遗漏题目。阅读题共享材料可合并题型单元格，题号与对应答案仍须可辨认。不要加入浅灰色解释性备注或面向教师的内部工作提示。前端默认不附单题详细讲解、变式练习、Excel、宣传图和教师版；使用者另行要求时再制作。

## 三、排版与质量检查

- 全文优先宋体；若当前设备没有宋体，询问使用者提供字体或确认替代字体，再排版。学科主题色用于标题、色块、表头与热力图；Typst 骨架的 theme 和 dark 使用该学科色卡 ink，热力图可结合 accent 和 tint，保持文字对比清晰。模板的 Songti SC、Arial Unicode MS 是字体名称示例，使用前检查本机实际可用字体，避免静默回退；最终检查中文、星号和其他符号实际显示。数学及理科公式使用真正的数学排版，不能以乱码或无法识别的替代符号交付。
- 内容用自然、简洁的中文，具体说明卷面考查，不堆砌套话。整体难度是基于试卷的专业判断，不是学生的实际得分或学情诊断。
- 输出前核对全部题号与答案、题目分值及总分，检查图表统计与底表一致。提取 PDF 文本并逐页渲染目视检查：色系、标题、表头连接、换行、截断、留白、图表、星号、公式和图片。修复后复验受影响页面。出现无法辨认的关键信息时回到提问步骤。

- 使用当前环境可用的 PDF 排版工具生成文件；先检查所需字体和工具。若环境缺少工具或无法读取试卷，说明具体缺口并向使用者询问，不把未生成的 PDF 描述为已完成。

## 四、标准案例对照与迭代（交付前必做）

标准样张在 [案例说明](../examples/案例说明.md)。优先对照使用者提供且有权使用的标准案例；无案例时参照公开版自制的版式骨架并按本包色卡和学科特点调整。使用者另给标准样张时，以其最新明确要求为准。案例只作视觉与结构参考，不能复制其题目、答案、分值、星级或历史缺陷；现行规则与案例冲突时，以现行规则为准。

1. 排版前打开并查看所用参考样张全部页面，识别页面规格、内容顺序、页边距、字体层级、颜色和页面疏密；不能只凭文件名或文字提取推测外观。
2. 生成初稿后，将成品逐页渲染；与已查看过的案例页面对照相应区域，目视检查：顶部品牌色块和标题、整体评估与亮点框、方块一级标题、带边框的考点热力图、深色通栏表头及连续逐题表；同时检查主题色、字体、留白、行高、列宽、分页、星级和公式。
3. 集中记录并一次修改明显差距，再重新生成并检查受影响页面；存在仍不达标的问题时继续修正。布局层级、视觉风格和可读性达到样张且下列最终检查通过后即可结束，不为细微装饰差异无限迭代。题量不同时允许自然增减页数、合理调整列宽和分页；不为强行对齐页数压缩字号、遗漏题目或把表格机械拆成多张。
4. 可将第 2 步的逐页视觉检查与最终检查合并，修改后复查受影响页面；若修改影响全局样式或分页，重新检查所有受影响页面。最终确认逐页文字与图形是否清晰、无重叠截断，公式和星号是否正常，表头与表格是否连贯；确认题号、答案、分值、题数与底表一致。仅在完成上述核验后交付。若工具或材料限制导致无法进行视觉对比或修正，应如实说明具体未完成项，不声称已基本复刻。


### 一句话亮点：色块与正文框

左侧深色标签和右侧白底描边正文作为一个整体，以同一表格行或等高网格实现；两格共用行高，外边上下齐平、紧密相接，不用两个各自定高的独立块。标签水平及垂直居中，正文左对齐并垂直居中；保留足够内边距。正文优先精炼为一句完整的话，不因容纳长文而缩小字号；换行时色块随正文一起增高。颜色取对应学科色卡，边框、对比和字体依现行视觉规则。

可直接复用 [Typst 版式起点](../assets/版式起点.typ) 中的 `highlight` 组件；其他排版引擎采用等价的单行双单元格结构。组件或布局发生修改时，用一行短文和自然换行的长文本各试排一次；每份成品检查实际内容：两侧边缘齐平、标签居中、文字与框线间距适当且不溢出，再与标准案例对应区域比较。不要为追求单行而删掉必要信息或压小字。
