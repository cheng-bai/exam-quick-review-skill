# 多维分析、自然文案与学生分层

## 完整快评需要回答六个问题

|维度|必须回答的问题|证据与边界|
|---|---|---|
|卷面结构|几道大题、几个作答项、有哪些题型？|由items统计；未知配分、时长留空；不能用题量代替分值|
|考点覆盖|本卷主要考什么？同一方法在哪些题反复出现？|列出题号与具体操作；单卷不能推出跨年命题趋势|
|难度分布|基础、常规、综合部分怎样分布？|五星计数、待核项和难点位置；不换算实测得分率|
|关键卡点|题目最难的一步是什么？|按读题、结构识别、模型、边界、推理、计算或表达归类；每类举本卷题号，不凭空诊断学生|
|分层讲评|这个层次的学生先讲什么、讲到哪里？|每档有顺序、讲评目标和复测；避免固定P0=最难题|
|学习建议|学生下一次学习具体做什么？|本卷考点和同类题练习方向；可视需要提供练习动作与复测方式，不许用“重视基础、加强训练”等空话替代|

上述维度构成正文，不必六个同形卡片。教师讲评PDF首页先有整卷说明，随后可排多维分析，再进入原题与解析。家长学生PDF可以单页概览另附多维分析；不能仅添加六个标题却没有分析。原卷疑点另列，遇错误题先修题，不把错误题用于能力判断。引用他卷样例只借鉴结构，不复制数据、题号或未经核验的数学判断。

## 学科适配

数学侧重条件、量词、参数、边界、方法选择与论证；物理侧重研究对象、运动阶段、图像、模型条件、实验及单位；英语侧重句法、语境、定位证据、推断范围与表达要求。无需为每卷凑齐所有卡点类别，以实际题目为准。

英语按实际题型取证：阅读呈现定位句、同义改写与干扰项区别；完形说明上下文和语境义；语法指出句子结构与语境；翻译交代指定词、语义和语法约束；写作依据题目任务及可取得的评分要求评价。听力缺音频时不推断听辨负荷。题目、选项和必要语境保留到足以独立核验答案。

## 讲评顺序随学生层次变化

基础巩固：优先选本卷概念与常规模型，明确必须能独立完成的步骤。常规提升：先处理跨知识点、方法选择和易漏条件，再练规范完成。综合突破：先处理综合转化、迁移和完整论证，要求说明方法依据。三档由教师选择或用户明确指定，不自动套分数段，不把学生固定贴标签。

同一题可以进入不同档，但目标必须不同。例如同一篇阅读，基础档定位题干与原文对应句，提升档区分同义改写与干扰项，突破档结合上下文论证推断范围；目标均须能由实际文本支撑。不能把同一段建议换个档名重复三遍。

底稿示意（ids必须换成本卷已核实题号）：
```json
{
  "public_review": {
    "learner_level": null,
    "teaching_routes": [
      {"level":"基础巩固","ids":["1"],"goal":"说清条件，再独立写出关键一步。","retest":"隔两天遮住答案重做，并检查条件是否写全。"},
      {"level":"常规提升","ids":["2"],"goal":"比较两种方法，说明选择依据。","retest":"隔两天做一道同类题，写出方法选择理由。"},
      {"level":"综合突破","ids":["3"],"goal":"完成综合转化，并检查结论的适用范围。","retest":"一周后改动一个条件复测，解释结论如何变化。"}
    ]
  }
}
```

学生仅描述“经常卡在起步”等情况时，结合证据给出建议档次并说明理由；信息不足则保留三档，不阻塞整卷快评。脚本的 --learner-level 只接收上述三个明确档名；selected档单独输出，通用成品保留。

## 文案审校

用“第×题先定位原文，再比较选项与原句的意思”替代“多维赋能、精准突破、全面提升”等宣传套话。少用“核心素养、思维深度、体系构建”等无题证的抽象评语。不制造焦虑、保证提分，也不用“这题都不难、其余只是熟练度”等话把真实困难一笔带过。

完整PDF检查每个维度是否有本卷证据；三档是否有不同目标；简图在手机上是否可读。统计检查、题目校核与版式抽查分别报告覆盖范围。
