# GO-ON 数学题目改编

把一道题展开为有数学联系、答案可靠、训练目的明确的题族。GO-ON 提供生成入口；交付前还要判断新题的条件、结论、解的对应与实际教学用途。

## 范围与按需读取

- 按用户指定的学段、数量、难度、形式与交付物执行；已有母题与上下文足够时直接改编。数学范围不限于高中，但不引入目标学生尚未学过的工具而不作说明。
- 简单改编直接给完整新题和必要答案说明；题族或教学设计再展开母题机制、训练顺序与通过标准。不默认生成长报告、PDF、学生教师双版或启动全库检索。
- 图形翻译、代换、符号、一般化、逆命题或边界较复杂时，读取[变化与数学边界](references/transformations-and-boundaries.md)中对应部分。
- 需要具体示范或核查典型失误时，读取[改编示例](references/worked-examples.md)相关题族；不把示例的数量、题型或答案套给新母题。
- 用户讨论葛军原讲法或要求出处时，读取[来源与解释边界](references/source-notes.md)。普通改编不必下载视频或加载整份字幕。

## 先明确母题与本次目标

保留完整母题、来源和必要图形，区分用户原题与自行补充。用足够支持本次改编的解析，确定：

- **对象与范围**：数域、定义域、参数域、几何构型与维度。
- **关系与条件**：限制对象的等式、不等式、位置、顺序、符号或量词。
- **任务**：求值、求范围、全部解、存在性、证明、反例或构造。
- **机制与边界**：哪一步把问题转成可解决的结构；需要什么条件；等号或边界能否达到。

不能只用“考查函数/向量”代替机制。如果母题尚未核验，先处理影响变式的疑点；条件有歧义时先从现有材料定位，不猜补改变答案的公式。能继续的部分照常完成，必要时只询问一个影响目标的缺失条件。

本次先决定要训练的主要动作，如识别代换、控制重复计数、找反例、解释符号变化、反求参数或验证取等。再选择变化方式。

## 生成入口：GO-ON 与补充动作

| 入口 | 可以改变什么 | 重点检查 |
|---|---|---|
| G：图与表示 | 代数、数轴、曲线、几何图形、表格等表示；由数想形或反向转化 | 是否等价，是否遗漏方向、符号、点或其他条件 |
| O：对象 | 正整数到实数，变量到表达式/函数，更换研究对象或情境 | 定义域、值域、合法解回代；对象性质是否改变 |
| O：运算 | 加减乘除、复合、关系中的运算结构 | 零、符号、单调性、成立条件 |
| N：个数 | 项数、变量数、集合元素数、重复单元数 | 新增自由度、计数与重复结构、维度限制 |
| 一般化 | 固定值到参数，特殊构型到一族构型 | 参数范围、临界点、退化与符号分支 |
| 反向提问 | 结论与全部/部分条件交换；从结果反求输入 | 存在性、唯一性、多解、可取范围 |
| 同理 | 将已经验证的单元作循环、对称、重复或组合 | 完整条件是否支持重复，交换是否保持问题 |
| 命题演化 | 逆、否、逆否，子条件重组、量词或联结词变化 | 真值、反例、否定范围与等价关系 |

四个字母是生成方向，不是互斥分类。注明主要变化及实际伴随的条件变化，不硬凑四类。单次主要新增障碍清楚即可；多维变化可以服务于前置、综合或探究，需说明承接关系。

数值变化可以用于熟练度练习；若数值跨过临界点并改变符号、解数或可达性，也有结构价值。不要一概禁止换数，也不要把仅增加计算量宣称为思维提升。增加参数通常属于一般化；删除条件通常属于条件调整，不能仅为了标签强称为 N。

## 验证并筛选候选题

生成候选题时，先写明保留的关系或研究主线、改变之处、学生新增的动作；核验后再决定交付。题族可共享机制，也可故意改变使某个方法失效，以研究边界，不要求每题沿用原解法。

针对实际变化核验：

- 运算与构型有定义；对象与参数范围明确。
- 代换后解能合法回代，未因隐含范围增根、漏解或排除全部预期答案。
- 证明题结论成立；求解题解集与边界完整；最值有取等构造或明确仅为上确界/下确界。
- “同理”保留了完整条件；反向问题检查真值、唯一性和可能的多支。
- 反例满足原假设、确实否定所检命题；修复条件后重新验证。

无解、假命题都可以成为判断、反例、条件修复或存在性题；明确任务和答案即可。不能把假结论交成“证明题”，也不能把意外无解交成预期有解的常规练习。仅枚举或数值实验不能代替一般证明。

筛选看：新增动作是否清楚、是否适合学段、与母题的联系能否解释、完成后能否观察到学习目标。合并无必要重复；保留用户要求的熟练度训练。难度来自新增障碍，不自动因题面更长、多了字母或参数而提高。

数学答案与证明、复杂题族按当前工作约定安排获准且可用的独立复核；不可用时第二遍自查，并如实说明范围。发现错误后修复并复核受影响结论，不把格式检查称为数学验证。

## 按用途交付

默认回答包括母题核心、新题的完整题干、答案与关键解析、简短改编说明。新题题干应自足，不依赖读者寻找“其他条件同原题”；若用户明确要简短改动清单则按其要求。

教师或题族用途，可在每题后增加：

> **保留**：哪条关系或机制。  
> **改变**：具体对象、表示、运算、个数、条件或任务。  
> **新增动作**：学生必须多完成哪一步。  
> **通过标准**：需要正确写出的关系式、证明、反例、边界或取等对象。  
> **使用位置**：前置、熟练、巩固、迁移、反例辨析或拓展。

按先备能力与新增障碍排序，不固定“先单维、再双维、最后压轴”。需要时说明未通过该题应补什么；没有学生作答时，这些属于备课建议，不声称实际失分率或已验证的迁移效果。

用户要学生题目版时，按其要求隔离答案、提示与含答案的来源链接；含提示、探究或教师版本遵守用户的内容约定。来源标签区分原题、视频概括、作者构造和自行改编，不将补写例题归到原作者名下。

改编授权只涵盖本次新题与交付物，不自动写回正式题库、改动母题资料、修改其他技能或外发。
