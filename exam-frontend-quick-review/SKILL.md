# 六学科试卷前端快评

用户提供试卷后，默认制作可转发的前端快评 PDF。用户要求数学教师版时，按[数学教师版规则](references/math-teacher-guide.md)制作教师版 PDF 和 Markdown；仅要求教师版时无须额外制作前端版。先读[制作规则](references/frontend-guide.md)，只查阅本卷学科的[学科要点](references/subject-guide.md)和使用者提供的相关知识图谱节点。配色读取[学科色卡](assets/subject-colors.json)。这些链接均为包内相对路径。

1. 阅读完整试卷与答案，优先查找同卷可用的解析版或已有 Markdown；优先提取 PDF 文字层，仅对扫描或识别不清的页面 OCR，并核对原图。识别结果是草稿，必须回看原卷，尤其核对题号、公式、图形和答案。
2. 确定学科、试卷名称、题目、答案、总分和逐题分值；按制作规则识别缺失或矛盾；仅涉及上海真题配分且有必要时查阅[配分参考与覆盖范围](references/shanghai-score-reference.md)。关键事实无法从资料确认时，向使用者提出具体问题，得到答复后继续。可先完成不依赖该答案的工作。
3. 建立一份逐题底表，记录题型、题号、考点、难度、分值、答案和来源。按这份底表生成考点分布和逐题表，核对题号、答案与分数总和。
4. 按统一版式生成 PDF；若环境已有 Typst，可使用[版式起点](assets/版式起点.typ)，替换全部示例并完成热力图；交付前必须按[标准案例对照与迭代](references/frontend-guide.md)逐页查看并对比使用者提供的标准案例或包内版式骨架，修正可见差距后再次检查，达到基本复刻的版式效果再交付。核查公式、颜色和内容。交付 PDF 链接，简短说明文件内容。仅在使用者另有要求时增加其他格式或教师讲解。

公开版提供[自制版式骨架](examples/案例说明.md)；可使用使用者提供的标准案例进行视觉对照。
