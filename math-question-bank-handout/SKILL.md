# 本地数学题库选题与讲义

## 按请求选择交付深度

- **仅现稿审校**：源文件只读，逐题独立核算，在任务副本或审校记录中保留来源、修订理由与待核项；复杂任务按适用约定复核。不另选题或重组讲义，除非用户同时要求。
- **快速找题**：用户说“找几道／给我几题／定位相关题”且未要求讲义时，交付完整题干、来源链接与定位、简短选题理由；按请求附答案，不默认补长解析、题型地图或教学总结。保留题干完整性和来源核验；单纯提取并保留原答案解析时，按“原题图与原解析的提取边界”执行；补解、纠错或数学审校时独立核对。
- **专题汇编**：用户明确要求分类、系统覆盖或讲义时，执行下文完整流程。列出多个知识点并要求“一类一个文件”时，按各专题分别盘点覆盖，不自动套用快速检索的少量样题配额；用户明确只要几道时仍以其题量为准。未指定时默认 Markdown；明确要求 PDF 就一并完成，不再等待重复确认。
- **停止条件**：指定题量时，找到足量、不重复、题意完整且符合要求的题后停止；未指定题量的快速检索先交 3–5 道不同入口的题，说明实际检索范围与可扩展方向，不声称找全。全量盘点或系统汇编不受此默认题量限制。

## 任务边界

用户给出一个高中数学主题后，从已有题库中**寻找、筛选、校核、分类汇编**符合主题的题目。主题可以是知识点、解题方法、题型或其组合；按真实题目确定分类维度。原题与来源文件保持只读。按用户指定的年级、地区、题量、版本和交付格式办；专题汇编没有指定题量时，先盘点可用题型和候选数，再决定能覆盖主题的收录量，避免任意只挑少量题后误称“已经找全”。不把题库内部文件名推断成原始命题学校、年份或高考真题出处。

此类主题分类汇编默认先交可审阅的 Markdown；只有用户已明确要求 PDF 时，才执行 PDF 阶段，单纯确认内容不等于授权导出。若用户对某次任务明确要求直接交付 Markdown 和 PDF，就依当次要求完成。不要把 PDF 编译、学生版或教师版双版本当成每次任务的默认交付。

## 定位与盘点

1. 先读工作区的 `AGENTS.md`、`README.md`、`目录索引.md` 等现有入口；入口不存在就记录事实，勿臆造。遵守库内限定的搜索范围。先从专题索引、主题文件名和已知相关目录找起，再用主题同义词及数学触发点扩展到相邻章节。若库内约定仅在用户明确要求时做全库扫描，就保持定向检索；用户明确要求全量盘点时再扩大范围。
2. 专题汇编建候选清单；快速找题只保留足以支持去重和引用的记录，不额外交付完整盘点表。清单字段：`来源文件 / 原题位置 / 题号 / 对应知识点或处理链路 / 匹配层级 / 题干完整性 / 答案解析状态 / OCR或图片风险 / 是否同题`。学生版、教师版、排版版、OCR 版要识别为同源版本，优先以清楚的题干配可信的解答，不重复计数。
3. 在写讲义前给出覆盖判断：有哪些不同题型、各类有多少可用候选、选择理由及未纳入原因。题目数量由候选质量与机制覆盖决定，不设固定上限，也不把本次某类的收录量变成通用配额。明确区分直接训练指定链路的核心题与迁移拓展题；直接匹配不足时说明范围，不用同章节关键词题凑数。在允许的定向检索范围内，主要机制已覆盖且后续候选仅重复已有训练入口时可停止；不把“无固定配额”解释成无限检索或未经允许全库扫描。

### 扩充已有分类稿

- 用户说“太少了／再多一些／还有没有更多”时，先核对已有文件与题号，继续扩展候选池；不能只解释原来的样题选择原则。优先原位更新各分类稿并续接题号，不擅自改成总合订本、重分已有类别或重复输出近同版本。
- 增量候选与已收题一起去重，并补齐原题、全部小问、来源与所需答解；教师追问、改编题和新增图像任务单独标注，不能冒充题库原问或用于充原题数量。
- 交付列出各类扩充前后数量并说明计数单位。完整多问题算一道或一组；小问数可另列，不能与原题数相加。类别不必等量：不足时报告检索边界，不把弱相关题放入核心组。

## 数学与来源核对

### 原题图与原解析的提取边界

- 用户要求“原题有答案、解析就带上”时，忠实保留已有内容；缺失处标“原库未找到”，不自动把补解当作原解析。单纯保留原解的提取任务，记录实际审校范围，不声称已逐题独立复算；补解或数学审校请求仍执行下文核对要求。
- 按题建立题干、考点、题图、答案、解析、来源位置的配对。OCR 中图片紧邻题块不代表属于该题：逐图对照对象、顶点、尺寸和题干描述，疑似错配回源查证；图不存在或错配无法恢复时明确标注。
- 区分原题图、解析辅助图及题解拼接图。为双版导出保留图的角色与来源；拼接图需要裁切时，保存原图与裁切依据，不能裁掉条件、选项或标注。具体版本隔离与缩图验收见 `lecture-pdf-layout`。
- 用户要求考点置于题干下方时逐题就地标注；学生版沿用分类与核心/关联考点，但考点中不嵌入求得的角度、答案数值、所求函数或已完成的推导。


- 每道收录题保留**完整题干**，包括所有小问、参数范围、选项和必要图形；规范公式排版不改变条件。若图片、OCR 或来源残缺影响题意，回看原材料；无法核实时标为待核或不收录，不补猜。
- 涉及补解或数学审校的专题汇编及附答案的快速找题需独立重算答案；单纯提取保留原解时按上文注明核验范围。仅找题不默认补解，但发现明显错误仍须标注。按主题核对核心定义、适用条件和常见漏解点；含分类讨论时检查分类标准是否互斥且穷尽、定义域与存在性、零值、端点、退化情形、参数符号、量词次序及分段结论合并。来源有答案也不能只照抄。
- 在讲义开头列出来源缩写与文件的对照；每题给来源缩写、可跳转的原文件 Markdown 链接及可验证的原题位置。先在目标阅读器检查含中文、空格和括号的链接能打开源文件；有真实稳定锚点时可直达题块，否则另列题号、标题或行号供人工定位，不拼造 `#L` 跳转。来源是 OCR 或本稿自行推导时明确标注。
- 原答案错误或口径歧义要在讲义题后说明原文结论、核对结论与理由。若用户只是要选题而不要求纠错，至少不要传播已知错误。不要改动源题文件来掩盖差异。

## Markdown 讲义（仅专题汇编）

按教学机制组织，而非照来源顺序堆题。一般包含：

1. 主题梳理：核心概念、典型识别信号、适用条件和可迁移方法；若主题是分类讨论，再说明分界点、互斥穷尽和合并步骤。
2. 题型地图：每类的触发条件、典型错误及对应题号。类型依据实际题目确定，不套固定目录。
3. 逐题内容：**完整题干、来源缩写、跳转引用、答案、解析**；原源无解析时可补写并标注“本稿独立推导”。必要时附一条迁移提示。
4. 洞察与教学建议：从所选题的真实共性、边界误区、难度顺序和源资料质量得出；写明检索覆盖范围、候选与收录数量、未复核项。

### 解析排版

面向学生阅读和教师逐步批注，按**一个推理动作一个独立步骤**排版：例如“确定对象与条件 → 找分界点 → 分情形求解 → 验证边界 → 合并结论”。一个步骤只承担一个判断、计算或结论；复杂算式可另起展示公式。根据题目需要用有序列表或短段落，不为简单题机械凑步骤。

不要把多个情形和边界核对挤进同一段，也不要依赖 Markdown 源码中的单个换行实现分行：多数渲染器会合并软换行。用独立列表项或段落保证渲染后仍可逐步批注；检查渲染预览中每个步骤的实际行距和公式位置。含空集、临界值或多种几何构型的题，尤其要把各情形分开。

输出文件用中文语义化名称，保存在当前任务可见位置。原题引用路径以交付文件位置为基准检查；若未来移动文件会使相对链接失效，说明移动约束或改用可持续的库内链接。图片要检查存在并位于对应题后。

## 交付顺序与验证

快速找题核对题意、重复、引用及所附答案后即交付；以下讲义流程只用于专题汇编。

- Markdown 阶段：核对题号连续性、题干/答案/解析配对、源题位置、来源链接、图片、公式定界符和勘误说明；抽查链接能否从讲义到达源文件。可用时安排独立复核：首轮只给题干、条件和必要图形，记录答案与边界后再提供原解对照；来源引用另外核对，并修正实际发现的问题。已看过原解时不称盲核。
- 脚本或 JSON 中转的公式，额外检查误转义的控制字符：例如 `\frac`、`\to`、`\right` 被写成换页符、制表符或回车；JSON 可解析不代表公式正确。逐公式试渲染，并视觉抽查新增内容；答案复算、结构检查与渲染检查分别报告，不能互相替代。
- 新类型长讲义先用代表题块做首次读者可读性检查：方法为何可选、关键转化是否可跟随、必要图是否齐全，见回归用例第5项。成熟模板沿用已有验收，不机械等待用户批准，也不全局固定字号或题量。
- 默认先交付 Markdown 路径、题型与题数、关键勘误和检索范围，等待内容反馈。审阅后按反馈修订 Markdown；除非用户当次明确要求直接交付两种格式，否则此时不生成 PDF。
- 用户已明确要求 PDF，且内容已确认或明确要求直接制作时，交给 `lecture-pdf-layout`，按需使用 `math-rendering-policy` 和 `pdf` 检查；仅确认 Markdown 内容不触发导出。以现有题号（跨源冲突时用“来源缩写＋题号”）、题干、答案、来源位置及核验状态作为交接记录，冻结题目顺序和数学内容；只改排版。发现实质数学错误时先在勘误记录说明再修正，不静默重写。仅当用户要求重新分类、扩充教学内容或同步双版本时使用 `high-school-math-handout-pipeline`；导出时只生成用户要求的版本，保留 Markdown 与 PDF。

## 避免的失误

- 不把快速检索的 3–5 道默认量套用到系统汇编或全量请求；快速结果不得声称覆盖全部题型。
- 不因教师版附答案就略过审计；特别关注分段式缺项和严格不等式端点。
- 不用一句“见原题”代替完整题干，不用只有文件名的引用代替可点击链接与定位信息。
- 不以“截距式”、等比求和公式等只覆盖非零或非特殊值的形式，漏掉零截距、公比 $1$、空集、退化图形等边界。

多主题分册或增量扩充的行为复核，按需使用 [分册扩充回归用例](references/分册扩充回归用例.md)，不为普通快速找题加载全部用例。
