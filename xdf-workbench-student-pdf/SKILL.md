# 工作台学生版 PDF

生成用于工作台通过题目文本匹配原题的本地 PDF。默认不上传，不声称本地检查等于工作台识别成功。

## 成品约定

- 只显示分类标题、连续题号、完整题目文字与已渲染公式；可保留一个简短的首页主题标题。
- 删除来源、学校与原卷题号标签、答案解析、编者校订提示、教学备注、导航和统计。来源及删除记录保存在内部台账，原稿不改。
- 不附图片。保留“如图所示”等原题文字，记录去图题号；不补猜图片条件，也不把此稿说成可脱离原图独立作答。
- 题目中的待判断解法、证明片段和辨错材料属于题干，不能因含“解法”“答案”等字眼误删。
- 题与题之间至少两行可见净空；分类标题到首题至少三行。默认正文 10.9 pt、行距 1.6，门槛分别为 34.88 pt、52.32 pt；换字号后按实际行距重算。
- 题干、选项、小问合为一块，整题不跨页。无页眉、页脚、页码，不加大块作答区。

## 小主题内的分层

固定按“小主题 → 题型 → 难度”组织。每个小主题中先放**填选题**（填空、选择合并一组），再放**解答题**；每组依次为**基础题 → 中档题 → 难题**。为减少识别干扰，页面使用“小主题”标题与“填选题 · 基础题”等简短分组标题，不加导航或分层说明段落。分组标题至首题仍留三行净空，标题不得孤悬页底。

- 优先沿用已审核的难度标注。没有标注时，由执行 agent 阅读原题、必要时核对解法，按同年级正常教学要求作教学预估，不要求用户逐题提供标签。
- 基础题：概念识别、直接代入或单一常规方法即可完成，条件较直接。
- 中档题：需要常规方法组合、适量变形、条件转化或有限的分类讨论。
- 难题：有较隐蔽的关键转化、较复杂的参数/逻辑分支、综合证明或明显更高的推理负担。不能只按题长、题号、分值或是否为解答题判难度，也不能为凑比例强行分配。
- 混合小问按完成整题所需的最高有效难度归档，不拆题、不重复收录；仅有多个小问不能自动升档。填选题也可以是难题，解答题也可以是基础题。
- 题型、难度及简短依据写入内部台账；依据不出现在 PDF。没有学生作答数据时，难度属于教学预估，不能写成实测难度或得分率。
- 保留小主题首次出现的顺序，同一“题型 × 难度”组内保持原顺序，排序后全篇连续编号，原题 ID 和原顺序仍可追溯。空组不显示标题，不为每组补题或编造题目。

## 执行

先确认原稿结构和题量。已验证的教师汇编结构及其他结构的适配办法见 [references/input-and-checks.md](references/input-and-checks.md)。不认识的结构先整理成该文档定义的 JSON，逐题核对，不能用泛化正则猜答案边界。

生成前完成逐题分层。JSON 输入可直接携带分层字段；教师汇编先编制内部 `分层标注.json`，用 `--classification` 传入。缺失或不合法的分层信息会在创建输出前停止，不能默认为中档题。判断不确定时核对题干与现有解析后给出保守预估，并在内部依据中标明不确定性。

优先复用本机已有 `math-handout-pdf` 引擎和 KaTeX 依赖，不修改旧技能。该引擎不随本仓库提供，需由使用者另行配置兼容版本，接口要求见 [输入与检查边界](references/input-and-checks.md)。脚本要求 Python 的 PyMuPDF、BeautifulSoup、Pillow，以及 Node、Chrome、KaTeX、markdown-it。用 `--modules` 指向已存在的依赖目录；缺少环境时报告具体缺项，不默默重新安装。

```bash
python3 scripts/generate.py \
  --src '/绝对路径/考点分类汇编-不等式.md' \
  --title '不等式' \
  --classification '/任务目录/work/分层标注.json' \
  --out '/任务目录/out/不等式-工作台学生版.pdf' \
  --work '/任务目录/work/不等式-工作台学生版' \
  --engine '/已有引擎/build-prose-pretty.py' \
  --modules '/已有构建目录/node_modules'
```

`--src` 支持已验证的教师分类汇编 Markdown，或经过核对的 JSON。输出目录同时生成无来源 Markdown；内部工作目录保存来源与抽取台账、构建稿、带核验标记的中间 PDF、核验 JSON、逐页 PNG 和每八页一张拼图。工作目录须新建，脚本拒绝覆盖已有产物。

脚本通过仅用于本地的 PDF 链接矩形标记每个题块，直接检查题块是否落在多页；交付前移除全部链接。实际测量 PDF 字框净距，并检查未归属文字、越界、图片、题号及公式渲染。不依赖历史 PDF、固定页数或固定题数。

## 验收与修复

脚本退出成功只是自动检查通过。还要查看全部拼图，并放大复杂公式、最长题和分类切换页，确认公式、选项、小问完整可读。逐题对照台账与源稿，特别核对删除引用是否只涉及编者提示，以及题型、难度、排序、原题 ID 是否正确、是否漏题或重复；复杂批量产物应独立复核。

失败时保留工作目录诊断，修复后使用新工作目录重建。只调整受影响的排版或抽取规则；不要为了过检漏题、删小问、放宽净距门槛或缩小到不可读。单题超出 A4 版心时明确报告题号，先调整公式换行等合理版式，无法满足就说明限制，不能交付为已通过。

禁止给每道题首段无条件设置 `break-after: avoid`：单段题会把相邻多题连成大组，造成大片空白。`margin` 不等于可见净空，必须测 PDF 实际坐标。

交付链接指向最终 PDF，简述题数、分类数、实际页数与核验结果；说明仍未上传。用户另行要求上传时，再按已授权范围执行上传流程。
