# 六学科试卷快评 Skill

把高中语文、数学、英语、物理、化学、生物试卷整理成面向家长和学生的前端快评 PDF。核心包含整卷判断、考点分布热力图、逐题考点、难度、分值和答案摘要；可按要求生成数学教师版。

## 使用

1. 将 [exam-frontend-quick-review](exam-frontend-quick-review/) 目录复制到 AI 工具支持的技能目录。例如 Codex 使用 `~/.codex/skills/`，保持内部目录结构，刷新或重启工具。其他 AI 请参照其技能安装方式；不支持 Skill 自动发现的工具可直接读取 `SKILL.md` 并按其链接加载资料。
2. 上传试卷，并尽量提供同卷答案、解析、逐题分值和机构名称。输入：“请使用试卷前端快评 Skill 分析这份试卷，输出 PDF。”
3. Agent 核对原卷、生成逐题底表和 PDF，并逐页检查公式、表格与版式。关键事实无法确认时，应询问使用者。

这是供 AI 使用的工作流程，不是一键生成器；需要具备文档读取及 PDF 排版能力的环境。可选使用 [Typst 版式骨架](exam-frontend-quick-review/assets/版式起点.typ)，需要 Typst 和合适的中文、数学字体。版式参考见[案例说明](exam-frontend-quick-review/examples/案例说明.md)。

公开版未附原始学校案例、试题截图与来源未注明的知识图谱；使用者可提供有权使用的案例和知识图谱。色卡基于提供图片的近似值，物理为浅蓝色。机构名称由使用者指定。数学教师版有专项规范，其他学科教师版尚无独立完整规范。
