# 年级多卷汇编任务模板

把方括号替换为本次信息；不适用项删除。可以直接交给支持本技能的 Agent，资料路径应在其运行环境可访问。

```text
请使用 $math-exam-insight-compilation，处理 [年级、学期、考试节点] 的 [多套试卷路径或目录]。
输出位置：[目录]；用途：[教师备课／其他]；范围：[全部／明确列出]。
先对照来源和既有转录，按规范卷去重并记录未匹配；选一卷做保留完整原题、图片、答案解析的题旁逐题分析，再覆盖其余卷。
然后以完整大题为单位，按专题、数学题型大类、题目形式和基础／中档／难题分层，制作总汇编及分册，避免一题一类。原题、全部小问、原图、来源和待核说明保留。
分册开头制作考点关系导图；每册去重完整大题至少 20 题时写基于本批数据的汇编说明，不足不写。删除分析稿和汇编中的平台作答次数、正确率、选项分布，原件保留。
给出阅读入口、逐卷和分类台账、母集/难度统计、待核与核验记录；检查公式、链接及图片，独立复核或说明限制。只交 Markdown 和必要图，不默认 HTML/PDF，不外发。
[按需补充：学校分组依据、例外题型、难度标准、其他产品或特殊隐私要求。]
```

该请求产生教师用途内容，包含答案解析和讲评，不能冒充无提示学生练习卷。阅读和数学复核应依据实际输入完成，不能只根据模板判定合格。
