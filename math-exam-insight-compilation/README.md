# 试卷洞见与分类汇编

**Skill ID：** `math-exam-insight-compilation`

**标签：** 高中数学、多卷汇编、考点分析、难度分层、分类汇编、教研洞察、来源追溯

把高中数学 PDF 试卷或可信转录稿整理为有原题依据的单卷分析、跨卷考情与分类汇编，帮助教师从题目中发现共同机制，并形成可用于备课的材料。

## 适合什么任务

- 同一年级多套月考、期中或期末卷：先按卷逐题分析，再按专题、数学题型、题目形式和难度组织。
- 按题型整理完整题干、图、来源及已授权保留的解析，制作专题总册、分册或指定用途版本。
- 依据实际题目研究考点覆盖、来源、难度结构及教学路径；按需编写汇编说明或制作统计图。
- 已有成果变更时追溯母集和依赖，只重建受影响的材料。

仅求单题解答、OCR、纯排版或正式题库入库时，应使用对应专项工具；本技能可按需与它们协作。

## 输入与使用

准备有权使用的试卷 PDF、清晰转录稿及已有答案解析，说明年级、考试范围、教师或学生用途和希望得到的成果。已有可靠转录及校订时优先复用。下载整个目录到支持 Skill 的工具中，保留 `references/`、`templates/`、`scripts/`、`examples/` 和相对链接。

示例指令：

> 请使用 `math-exam-insight-compilation` 处理我提供的同年级月考试卷。先核对来源、统一卷题编号，在原卷基础上逐题分析考点与难度，再按专题和数学任务制作分类汇编。保留题干、必要图片和来源；统计及结论请给出可复核依据，最终交付 Markdown。

## 核心流程

1. **锁定范围**：核对文件与独立试卷，确定年级、用途、产品及统计母集。
2. **建立底稿**：保留完整题干、小问、必要图和来源，采用稳定的卷题 ID；OCR 歧义回看原件。
3. **单卷分析**：逐题记录考点、关键动作、边界和有依据的难度判断；已有解析按需要检查，不将搬运等同独立重算。
4. **跨卷分类**：专题下按具体数学任务与共同机制归类，再按填选/解答和难度组织；解释同练价值，避免只按题号归类。
5. **统计与洞察**：区分独立卷、学校、题目、小问与展示次数；每条跨题结论能追溯题目，不把入选题分布冒充整卷考频。
6. **制作与检查**：按约定生成卷内分析、汇编、说明或图表；检查来源、题目完整性、版本内容、统计和实际显示，记录未覆盖部分。

## 交付与验证

默认以 Markdown 保存，按需求输出分类地图、原题块、来源索引、统计记录和核验说明；学生版与教师版的内容边界由本次用途决定。图表、PDF 和额外双版不是强制默认产物。规则难度是编制判断，不代表真实学生正确率；案例的题数、学校分组及阈值不可直接套用新批次。

`scripts/check_records.py` 和 `scripts/check_batch.py` 检查结构、计数及已声明的依赖；通过不代表数学正确或版式已经目视验收。维护技能时可分别运行 `python3 scripts/test_check_records.py` 和 `python3 scripts/test_check_batch.py`。真实材料的数学、来源、公式及图形需要另外核验。
