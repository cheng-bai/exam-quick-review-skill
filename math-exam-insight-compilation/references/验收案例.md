# 验收案例与证据等级

这些案例从已有 tjg 分类边界提炼，仅用于回归；不预设新试卷的类别数或频率。给 AI 输入题干与图形时先隐藏预期判断，再由独立复核者对照以下标准。提示词回放未运行前，不能把本文或脚本检查称为行为通过。

## A：同叫最短路，限制不同

输入：圆锥/棱锥沿指定侧面绕行的题；公共棱上取动点使两段线段和最小的题；另给圆柱内部截面折线题作排除对照。读取完整原题及指定路径，不仅给“最短路”标签。

预期：可以提炼共同的平面化思想，但分别定义侧面路径展开与公共棱折线翻折；核对绕行方向、经过哪些面、交点是否可达、求全程还是指定路段。内部截面不因出现圆柱就归入圆柱侧面行走。

失败：只按几何体/关键词合并；用“两点之间线段最短”代替路径合法性；将两个类别的重叠题次数相加。

## B：球任务覆盖不等于容球高频

输入：由球半径/面积/体积直接互求的题；截面勾股题；容器中最大球题；外接球题。保留接触面、球心位置及边界条件。

预期：区分直接公式、截面关系、内外切约束与最大容球。上层“球相关”统计不能代替细任务统计；某任务只两卷出现就如实报告。短题可作入口检查，频率相同也不意味分配相同课时。

失败：为了达到旧样本至少三卷的阈值，把不同球任务合并；写“球每卷有，所以最大容球必考”。

## C：固定角到动点角的能力增量

输入：固定异面直线角、固定线面角、指定二面角，以及含动点范围/存在性/正弦和最值的小问。前问条件一并提供。

预期：共同动作是先辨认角对应对象，再计算；不同角的三角比与方向须分别解释。动点题追加参数域、端点/内部极值及合法取等检查；不能把正弦和最值当成角度和最值。固定题通过标准与动点题不同。

失败：只有向量公式而不辨认对象；所有夹角一律取绝对值；按题号或计算长短排梯度；凭题目要求推断学生实际薄弱。

## D：计数、来源与交接

运行 `python3 <本技能目录>/scripts/test_check_records.py`。合成夹具检查：同类重复记录去重并提示、跨类重现不抬高全局题数、迁移不抬高直接覆盖、待核小问排除、排除卷不进入分母、缺图与失效来源报错、起始行与哈希校验、规范 ID 冲突和错误记录拒绝。

计数脚本在真实题意已核验的记录上才有意义；没有原题输入时，这些测试不等于数学与教研验证。

## 触发边界

应使用：给定一批试卷，比较同类任务并形成教研洞见和分类练习。
不应使用：只求一道题答案；单卷从零补答案；只修 PDF 排版；正式题库迁移；只做学生心理判断。
只有一卷仍可分析跨题机制，但不能宣称跨校频率。

## 分开报告证据

结构检查、合成计数测试、真实提示词回放、独立数学复核、学生实测各自记录。当前三个数学案例只代表待回放验收设计，须在新试卷到位后记录实际输入、输出、复核与修订，才能评价迁移效果。


## 分类成品与版本回归

| 请求/材料 | 应观察到的行为 |
|---|---|
| 做分类汇编，源分类只到“集合与逻辑”或“选择题” | 根据真实任务细分，正文有类别标题，索引与书签可定位；不能只产统计表。 |
| 两题均用均值，一题乘一配凑，一题取等点被约束排除 | 解释共同上层与不同训练动作，不无差别归为最值类。 |
| 学生版恢复每题原本题分析，删除【填空题】 | 保留授权完整分析、不自动加参考解答，题号与来源保留，版本名准确。 |
| 教学建议定位具体题目和解析步骤 | 完整题干/图后标关键推理，建议指回该步骤，不只列题号或方法名。 |
| 紧凑PDF，标题彩色 | 分类可识别，图和公式可读，不强加大块留白/封面，合订保留分类书签。 |
| 整理到结构化文件夹 | 阅读入口区分用途与版本，包内链接/图片可用，PDF副本哈希一致，原文件保留。 |

需实际回放后报告行为结果，不能把写入案例称为回归通过；类数、页数、具体色值不固定。

## 低返工流程与说明回归

以下为真实任务回放的评价依据，未回放前只是验收设计。结构脚本另运行`test_check_batch.py`：覆盖母集、允许重叠、漏题、错母集、同序、已声明依赖失效与错误输入；不能代替下列教学或显示判断。

| 请求/材料 | 应观察到的行为 |
|---|---|
| 给一份定稿MD，“只输出干净工作台PDF” | 冻结内容，走工作台专用导出；不重分类、不重新OCR、不全量补解，不冒充完整带图练习。 |
| “两份并集等于原册，允许题目重复” | 引用具体母集ID，使用union_cover，核查并集与交集；不误用partition拒绝重复。 |
| 同名立体几何存在96题和159题版 | 先查本次母集与修订；不能用54＋42题声称覆盖159题。 |
| 原题干不变，仅改教师答案 | 更新底稿和依赖该解的教师/报告；确认不影响条件分类难度时复用纯题目版，不重跑OCR。 |
| 只改网页主题 | 重建显示并查桌面/手机；不重做数学、来源或学校统计。 |
| 学生PDF隐藏来源，要求说明与学校热力图 | 逐题回查本批映射；不猜学校，不复用旧批次分母；来源不全时继续无关工作并说明缺失关系。 |
| 联考同卷多校、各校卷数不同、某组无样本 | 学校与独立卷分开，频次/学校覆盖分母分开，零样本不写0%，不把参与学校数当独立命题数。 |
| 某类只有中档题，题型说明要求进阶 | 如实写缺档，按实际题说明训练价值；不编造基础题、难题或实测薄弱点。 |
| “先评估汇编说明框架并纳入流程” | 交付评估与流程，不擅自启动专题PDF和图包生产。 |

对脚本声明缺失依赖的场景应观察到明确限制说明，而非宣称全自动发现全部受影响文件。真实新PDF输入、多产品导出与平台识别各自验证，不能用合成用例通过替代。

## 考情报告与简版说明回归

以下是行为评价标准，不是已经通过的测试。回放时仅给真实请求、材料和技能入口；不要把本表预期作为任务答案提供给执行者。记录输入版本、所读规则、实际产物、复核者与限制。

| 请求/材料 | 应观察到的行为 |
|---|---|
| 只写分类汇编的一页前言 | 交代样本、核心考法、选题与用法；保留内部证据，不强加完整报告、典型题全文或三图包。 |
| 两校同阶段卷，无往年卷，要求“说明今年强化了什么” | 给当前差异和待验证点，不把横向比较写成跨年强化；明确缺少可比旧样本。 |
| 完整原卷台账与筛选后的难题集来自同批卷 | 分开分析集合和分母；难题选编占比不当整卷难度结构；选编未收录不判原卷未考。 |
| 题号前移但题型数量改变；综合题只有大题总分 | 同时看题型内位置与任务，不凭原题号推难度；不平摊小问配分或跨考点重复加总。 |
| 三卷中两卷确认考某机制，第三卷缺相关页 | 固定已声明样本，报告确认命中2、未知1及已确认覆盖下界2/3，不报确定未考或改成2/2的全覆盖。 |
| 给现有有效解析，无学生作答，要求典型题与讲评建议 | 完整证据就地可读，复用原解；按需补关键分叉和追问，推演错解不称真实失分，无正式细则不编官方评分。 |
| 培训示例含删减清单、学校排名、至少6题和四周安排 | 吸收方法，不套未经核验的事实、固定配额或周数，不自动访问平台/生成预测卷。 |

重点检查新增报告模式没有破坏既有只导出、全量/选编区分、源解析保留、按需重算、纯题目答案隔离和局部重建规则。
# 年级多卷移交回归点

- 同卷别名有证据才合并；找不到原 PDF 的卷保留并标未匹配，不能输出全部匹配结论。
- 从独立分析表迁移到逐题就地分析时，原题、小问、图、答案和来源仍完整，平台作答统计从指定成品中去除而不改原件。
- 大类必须有共同数学机制；一个技巧一个标题且每类一题不算合格。20 题及以上出说明、不足不写只适用于用户确认的本模式。
- 隔离解压后相对路径、图及台账可读；不得只复制汇编目录导致卷或图片丢失。重建不得覆盖新加的导图、说明入口；原始目录和交付副本分开。
- 题目 ID、档位、分册并集守恒只能证明结构；来源匹配、公式实际显示与数学正确性分别报告。
