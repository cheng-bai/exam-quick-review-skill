# 交接与产物模板

## 最小记录合同（v1）

自然语言模板负责教研判断；交接 JSON 负责追踪与计数。保存为任务目录的 `交接记录.json`。JSON 内路径相对该文件所在目录；允许用户本机来源绝对路径，但可分享产物中的图片使用相对路径。UTF-8。

| 对象 | 必填字段与含义 |
|---|---|
| 顶层 | schema_version=1；papers、questions、units、groups 四个数组 |
| papers | id、title、included 布尔值；excluded_reason（included=false 时非空）。同卷扫描/OCR/学生版/教师版只建一个规范 paper，所有题共用其 ID；此文件只对应一个可比统计范围，混合模块另建记录。 |
| questions | id、paper_id、origin_id（原始大题唯一身份，重复版本映射同一记录）、original_number、stem（完整大题和全部小问）、images（路径数组）、source（path、line 起始行整数；可选 anchor 明确 HTML id、sha256）、stem_complete 布尔值 |
| units | id、question_id、subquestion（规范 token：whole 或 s1、s2、s1.1 等；原小问标号可另存 display_subquestion）、task_status（verified/pending）、solution_status（verified/conflict/missing/pending）、key_action、boundary、verification_note、training_role；task_status=pending 必须说明待核原因 |
| groups | id、title、definition、include_when、exclude_when、members 数组 |
| members | unit_id、kind（direct/transfer）、reason（本小问为何命中或迁移） |

`stem_complete=true` 前须人工核对题干、全部设问、图形；这是审阅结论，不是脚本生成的证明。规范 ID 不随题型、题序或版本变化。小问身份只能使用 whole 或 s 开头的正整数层级，禁止将全半角括号、空白等展示差异建成不同单元。同一道原题只建一个 question；展示重复、来源副本和其他所属类别引用它。

题意不清时 task_status=pending；题意明确但源答案冲突时可为 task_status=verified、solution_status=conflict。作为已核验评分题提供时须有足够核验依据，可由源解析关键链、答案与边界对照检查取得，不强制独立重算。仅汇总或待教师审阅练习保留真实pending状态，不为升级标签额外求解；冲突题保留教师核验说明、学生版暂不作评分使用。验证只覆盖命中小问时，不称完整大题已全部重算。可选verification_method记录source_review/targeted_recompute/full_recompute；格式调整或源解析搬入不自动升级状态。

示例数据见 [counting-fixture.json](../examples/counting-fixture.json)：其中题干是合成计数夹具，不可交付为真实试卷。真实题必须替换为完整原文；严禁直接把夹具复制成教研成果。

工具调用：

```sh
python3 <本技能目录>/scripts/check_records.py <任务目录>/交接记录.json --check-files
```

`--check-files` 检查来源文件存在、起始行有效、可选 SHA-256、明确 HTML 锚点及图片文件存在。它不检查任意 Markdown 链接、网络 URL、图像内容、公式渲染、双版答案泄漏，也不能验证 stem_complete 的真实性。生产交付必须另做成品检查。输出 JSON 包含错误、警告、各类计数、全局去重计数；有错误返回非零。

多版本与拆册在旁边保存`批次清单.json`，引用此记录并冻结母集、产品题序和输入版本；格式见[低返工执行流程](低返工执行流程.md#批次清单与检查工具)。不要把分册配置、来源副本或重复展示再写成新的question。既有v1题目合同保持兼容；学校映射、难度和产品状态使用按需关联表，均以规范ID回连。

## 多版本成果包

用户要求整理成果，或已经产生多用途版本时，建立统一阅读入口，按实际产物设目录，不为凑结构建空目录：

- 00-阅读入口：突出最新可用成品、版本内容、题数/页数与限制。
- 最新使用版：合订PDF、板块分册、对应Markdown分别放置。
- 教研洞察、完整教师汇编、纯题目学生版：仅收入实际存在且有用途的版本。
- 分类台账与核验：分类映射、勘误、独立复核；来源与图片：必要文件；复现资料：数据和脚本。

复制并整理引用，不移动或删除原文件；草稿、旧备份、全页预览留工作目录。可分享包采用包内相对链接并收齐依赖，核对副本SHA-256、原题/公式不变、图片和目录目标。数学或代码中的链接形状表达式不当成文件链接修改。脚本保留原机器绝对路径时说明调整要求，不宣称开箱可重建；本地整理不代表外发授权。

## 按需任务产物（本次合同优先）

以下是可选产物模板，不是每次必交清单。只分析、只导出、拆册或只要汇编说明时按本次合同选用。代表选编和双版只在需要时生成；全量归档、选编和纯题目/含分析版不得互相冒充。

1. `教研洞见报告.md`：范围、分类地图、频率与价值分开判断、证据洞见、复习决策、限制。
2. `分类汇编-教师版.md`：代表练习选编，默认沿用源解析并加格式整理/关键标记；仅缺漏/冲突部分补写。类别说明、主练小问、每题完整题干/图→答案→解析→就地讲评；来源可跳转，冲突与自行补解有标记。
3. `分类汇编-学生版.md`：按合同提供同序原题、图形、主练小问；纯题目版不含答案，留白按用途；含本题分析版完整保留授权原分析，不额外加入参考答案/解析。
4. `来源与分类索引.md`：卷名/大题/小问/类别反查，来源与修订副本对应。
5. `交接记录.json` 与 `分类统计.json`：可复算任务记录与工具输出。
6. 全量源题块汇编：大板块→具体考点/题型→完整原题、源分析、源答案解析和全部图片；与代表选编区分，简单题只汇总。
7. `核验记录.md`：实际审阅范围、数学复核、引用/图片/公式/双版检查、勘误和剩余待核。

### 成品交接检查

交付Markdown均有返回阅读入口，长文件首部有明确锚点大纲。逐题核对双版相同类别和题序、完整题干/图像一致、来源定位、有效答案与核验状态匹配。纯题目版人工检查是否混入答案；含分析版核对授权栏目完整性，不将允许的原分析判成泄漏，不能只靠关键词扫描。公式必须实际预览；PDF 如被要求，检查实际渲染页面并记录页码。缺页/缺图等影响题意时不输出确定结论，保留待核清单并完成其他可独立部分。
