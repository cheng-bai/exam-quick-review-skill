# 技能协作与回传

以技能名在当前可用清单中定位实际 SKILL.md；不要硬编码本机安装路径。先确认可用，再读所需流程。不把技能名当成已经执行的证明。

| 触发条件 | 技能 | 交接约束 |
|---|---|---|
| PDF、图片或 Word 尚未转成完整题目 | 对应已有转录技能 | 完整题干、图片、原页码/题号、识别疑点；保留原件。按本机已确认流程使用 MinerU，不另建 OCR 系统。 |
| 有答案与解析，需检查数学 | 直接逐题独立核算 | Markdown 源只读；在任务副本和审校记录中逐小问映射回规范 ID，保留来源、修订和待核项。图片仍回指原来源；复杂任务按适用约定复核。 |
| 缺答案或完整解析 | 直接补写并验证 | 生成任务副本，保留全部设问和来源；独立补解须标记，不冒称原答案，缺图或歧义影响解答时标记待核。 |
| 明确要求正式题素/规则难度 | shanghai-math-difficulty-atoms | 保留该技能规则、版本与限制，不混用其他难度算法；无需正式分时本技能只写关键动作。 |
| 已有洞见，需要能力台阶 | math-method-ladder-handout | 候选题、终点、关键障碍与边界；返回题序、各题角色、通过标准。新增题须有来源或自编标记并独立求解。 |
| 已定分类，需完整 Markdown 汇编 | math-question-bank-handout | 使用指定候选、已确定分类及顺序；不启动无关全库检索，仍保留其原题、数学和来源检查。 |
| 双版讲义/PDF | high-school-math-handout-pipeline | 使用冻结内容和单一母稿；本次仅 Markdown 时不执行 PDF 专用版式/编译阶段。需要 PDF 时遵循其配套排版与视觉验收。 |
| 新东方工作台识别学生PDF | xdf-workbench-student-pdf | 单独用途合同；按技能去图、来源与答案解析，保留内部图依赖记录，不能冒充完整练习。PDF完成不等于上传或识别通过。 |
| 汇编说明与三图 | data-analysis、已有PDF生成/检查技能 | 遵守本技能汇编说明合同，从同批冻结数据生成表图；不另建与台账脱节的统计。 |
| 网页阅读入口/项目复盘 | frontend-design，或适配的HTML说明技能 | 先按报告长度与读者用途选择版式，不机械套工程图纸模板。首屏展示范围与结论，长表和详细依据可展开，正文与链接不丢；验桌面、手机和实际交互。 |
| 备课探查或真实作答诊断 | coordinate-learning-diagnosis | 只有试卷时走备课预判；学生诊断另需具体作答证据。 |
| 明确要求结构难度评分 | question-difficulty-analysis | 使用其完整评分规则和输出；不将其六维分当作旧七校能力分类或实测成绩。 |
| 题型族命题研究/变式 | shanghai-math-question-authoring | 按当次授权确定题源范围；不因本技能调用而默认扩大到网络或命题。 |

阶段完成后返回：规范 ID、产物位置、核验范围、修订项和剩余阻塞。实际题意与数学证据优先于已冻结的结论：若后续发现错误，更新核验记录，列受影响分类/洞见/题序，重新复算计数及重建受影响双版，保留修改前任务副本。

相关技能缺失时，继续不依赖它的工作，报告实际替代方法与未验证范围；不声称调用不存在的技能。独立复核可用且获准时按风险聚焦分类、来源、公式与已有疑点；默认不把全部源解析换成独立解答。需要重算的缺漏/冲突小问可先独立推导再对照；已看原解者只能称对照复核。简单汇总由结构检查与抽查完成，不为形式重复数学求解。
