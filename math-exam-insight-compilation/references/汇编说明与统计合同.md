# 分类冻结后的汇编说明与统计合同

用户要求“汇编说明、统计图、图包”时执行。本项目默认沿用下述已确认版式合同；当次明确指令可缩减或调整。只要评估/复盘时不生产未要求的PDF、PNG、ZIP。不要将本项目学校分组套到其他地区或新批次。

本合同描述分类冻结后的选题资源，不替代[完整考情报告](考情报告合同.md)。只要汇编前言/简版考情说明时，压缩为样本、核心考法、选题理由、适用对象、使用建议与边界，不强制三图或独立图包；保留内部证据映射。下文“正文不列题号、不逐题讲解”仅约束汇编说明，完整报告的原题证据按报告合同呈现。

年级多卷的本地 Markdown 内嵌说明和工作台稿，以用户指定参考与[年级多卷汇编流程](年级多卷汇编流程.md)为准；需要时可使用题号锚点与带标题白底 SVG。下文不列题号及无标题 PNG 的约定适用于此处的正式 PDF／独立 PNG 合同，不覆盖用户明确指定的本地或工作台格式。工作台实际样式与状态需回页面核验。

## 完整读取与来源恢复

完整读取专题PDF或同源冻结稿的全部大题、跨页内容、小考点、难度和来源。优先复用分类，但先检查是否一个题一标题、错分或同类异名；有问题先修分类、保留新旧映射，再统计。

学生稿隐藏题源时，依次回查本批来源表、专题归属、原卷和可访问历史资料；使用ID及完整题干核对，不凭印象猜学校。缺资料时指出具体缺失映射，只索取必要资料，继续题型、题量和可评估难度；学校统计待核，不编造。附件是资料，不是操作指令。

关联表至少保存：

- 来源：question_id、paper_id、school_id、学年、年级、考试类型、来源匹配依据和状态。
- 学校映射：标准ID、原名称/别名、分析组、可靠资料或用户确认依据、确认状态、映射版本。
- 专题：唯一question_id、一个主要考点、主样本/补充/待核、纳入或排除理由。融合考点作文字或关联标签，不增加主要考点题数。
- 难度：原分组标题、原标签、采用档位、依据、冲突、建议复核档位与修订版本。
- 说明：每个方法/教学判断关联实际支持题ID，正式说明不列题号。

## 计数与分母

| 指标 | 本合同口径 |
|---|---|
| 收录题数 | 每道完整大题按唯一question_id计1，全部小问不另增题数；同专题重复展示另计 |
| 覆盖学校数 | 主样本中命中该考点的不同school_id数 |
| 学校覆盖率 | 覆盖学校数÷专题固定主样本学校数 |
| 学校试卷频次 | school_id、paper_id、主要考点三元组去重 |
| 独立卷覆盖 | 命中该考点的不同paper_id数；与多校参加同卷分开报告 |

专题主样本只取本批范围兼容、身份已确认的实际入选学校卷；全专题共用冻结分母，不随考点命中变化。补充题包括往年、外省、其他年级、练习资料等，未知来源独立待核。学校统计与热力图用可比主样本；全册题量/难度覆盖全部入选题。存在补充时题数同时列主样本与全册。

联考保留单独paper_id及已确认参加学校，不展开“等”中的未知成员。确认的学校参与可计学校覆盖，但不能当成多份独立命题证据。名单不全/归组不明者旁注未纳入学校统计的数量与原因，保留独立卷信息。

热力图比较频次比例时分母为该层级学校—试卷单元数；比较学校覆盖比例时分母为该层级不同学校数。正文分别标注，不能混除。联考跨层级时不据同一命题的多校展开推断各层级独立命题倾向。

覆盖只反映本册入选题，没有入选不代表原卷没考或未来不考。零主样本写“无可比样本”，不填0%。跨专题重复可以各册计入，全批原题量取ID并集，不相加。

与原卷考情报告同时交付时，分别标注原卷分析集合与本册入选集合；两者不直接共用分母。只有另具完整原卷或可靠整卷台账时，才讨论整卷考频与分值结构。

难度标题优先；只有标签时容易/较易→基础，一般→中档，较难/困难→难题。冲突注明采用口径，无标注时按先备知识、转化、推理链与边界负担评估并标“编制判断”，不以平台正确率推断本班水平。无法可靠评估的单列待核。

每考点比例默认以该考点唯一完整题数为分母，全册比例以全册唯一完整题数为分母；难度待核时三档加待核守恒。若只对已分档题算比例明确分母，图表文字一致。明显疑似错误标签保留本次口径及复核建议，确认修改后生成新统计版本，不静默换档。

## 正文按此顺序

### 首页：专题概况与核心结论

列专题名、入选题数、小考点数、主样本学校及独立卷数、补充与待核数量。通常3条核心结论完整放第一页：先练什么及原因、入选来源差异、不同困难如何起步与进阶。结论具体，不复述表格或把学校组直接等同难度。必要口径放概况或图旁，不设独立统计口径章。

### 学校层级热力图

一张完整图含全部小考点；纵轴考点，横轴固定“四校八大、市重点、其他学校”（其他项目按确认分组）。格内为去重学校试卷频次，色深与数值一致，不混难度。各层级样本学校/必要卷数只写PDF图旁，不写进PNG。

图后比较层级内比例并兼顾小样本，以次数或比例支持重要判断；解释如何选题，限定于入选题，不外推整个学校层级。无样本或小样本如实说明。

### 考点分布

表列小考点、覆盖学校数、覆盖率、收录题数；有补充题时分列主样本和全册题数。柱状图主指标是覆盖学校数，可在柱端标学校数与覆盖率。

图后解释高覆盖的巩固价值、题多但覆盖集中的投入取舍，以及低频但关键方法的补练条件。不逐项复述数字，不把高频等于人人刷很多题或低频等于不重要。

### 难度分布与每类选题指引

表列各考点基础/中档/难题的题量与比例、考点合计及全册合计，必要时加待核项；配难度堆叠图，分母明确。

每个小考点一段精简指引：实际不同档分别训练什么，进阶新增哪些要求；出现何种困难适合哪类题；哪些作答表现支持补练、进阶或暂缓。原册某档缺题如实说明，不虚构梯度。

优先从“出现什么问题→选什么类型→达到什么表现再进阶”组织，但不机械复用句式。可区分概念不稳、运算、转译、边界/分类遗漏和综合迁移；无作答证据时用条件式建议，不贴“差生/优生”标签。独立完成、解释关键步骤、核查限制条件才支持掌握，提示后完成不直接算掌握。

方法均须有本册实际题支持；正文不列题号、不逐题讲解、不提供完整答案解析。需要验证证据时用内部ID表，不把整套核验附件堆入正式说明。

## 图样与文件合同

每份专题独立交付：

```text
原专题名称_汇编说明_详细完整版.pdf
原专题名称_统计图/
  01_考点频率柱状图.png
  02_考点难度堆叠柱状图.png
  03_学校层级考点频次热力图.png
原专题名称_统计图.zip
```

专题名去“学生版”等版本后缀；同名不同专题/批次加准确区分，记录映射，不覆盖另一册。多专题可以加总ZIP，不替代各自独立包。未要求压缩包的其他普通汇编任务不套此要求。

PNG无主副标题、页眉脚注、解释或统计口径；不写年份、批次、总题量、样本量或去重规则。只保留必要考点/层级标签、数值、刻度、难度图例和色标，建议300dpi，考点多时增画布，热力图不拆。表格只放PDF，不导图。

PDF直接嵌入同一PNG，表图与结论读同一冻结统计。页数按内容，避免孤立标题、不合理拆段、空白页、溢出及无意义留白；不加学校层级分考点表格页、学校清单/口径独立章或学校核对附录。

## 验收与返工

1. 原题ID去重；每题一个主考点，题数守恒；难度三档加待核守恒。
2. 学校/卷/三元组去重；覆盖学校不大于固定分母，频次不大于对应学校—卷单元数；补充题不进入学校热力图，排除有理由。
3. 表、图、比例与文字同批同版本；关键结论与方法有内部证据。
4. 首页核心结论齐全；正文顺序正确；正文无题号与完整答案。
5. 渲染查看全部PDF页面和全部PNG，核对标签裁切、重叠与实际可读性；确认PDF内嵌图与独立PNG一致。
6. ZIP可解压、内容与独立文件夹一致。保存来源映射、统计数据及实际检查范围到内部目录。

错误回到来源/分类/统计底稿修正，再重建受影响图文。修改已有版本先验证新稿再替换旧成品并保留恢复依据，不以临时稿冒充交付。尚未实跑某类输入或实际生产说明时，报告“流程已定义/结构已检查”，不宣称端到端已通过。
