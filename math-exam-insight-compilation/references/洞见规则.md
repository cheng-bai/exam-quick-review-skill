# 洞见与分类规则

## 分类的四个比较维度

| 维度 | 要回答的问题 |
|---|---|
| 所求对象 | 是求数值、关系、范围、存在性、位置，还是证明或反例？ |
| 关键转化 | 从什么表示转到什么表示？这一步由哪个原题条件允许？ |
| 适用条件 | 方法必需哪些条件？前问能引用哪些结论？ |
| 边界检查 | 定义域、端点、退化、方向、量词、可达性或等号如何改变答案？ |

先建立知识大板块，板块下按具体考点/题型组织动作类；知识目录与机制对照同时保留，不以58类等固定数量套新材料。类别标题写为“对象/条件＋关键动作＋目标”。分类可以交叉，但必须分别说明直接命中的任务；不能将方法类当作互斥学科模块加总。固定角与动点角可以在共同方法上层汇总，在具体任务层必须区分参数范围和取等验证。

每类写：定义、纳入条件、排除条件、直接命中单元、迁移单元、至少一处边界对照。没有真实排除题时明确“本批暂无排除样本”，可提出待检验情形，但不编造原题。

## 从解析步骤到建议

每项实质结论都有可检验的“结论→题目/小问→解析动作→建议”链。完整原题与必要图后，展开足够的源解析或补充推导，证据标记直接放在支持判断的操作旁：

> 【证据E1｜量词转译】写出本题实际转译关系、适用域与为何等价。
> 【建议T1←E1】练习先写转译关系再求最值；通过标准是本题的正确关系式与边界说明。

标记方便追溯，不固定字母或颜色，不把示例关系套新题。“注意端点”“加强分类讨论”必须落到实际端点/分支、该步骤的允许条件与可观察验收。统计支撑频率，不能替代机制解释。小问依赖说明前问提供什么、后问新增什么。区分源稿判断、已复核推导和教学推断；无学生作答不写真实错误率、得分预测或学校难度排名。

## 洞见强度与证据

- 独立来源是数学任务的原始来源，而非文件副本。两道不同数字的同源改写应说明关系，不能假称跨来源发现。
- 两道独立题支持的是本批共性，不自动成为普遍定理；数学恒等关系仍须给有效证明或依据。
- 真正的洞见说明为什么这种差异影响选方法、训练顺序或通过标准。只列“常用向量法”“注意端点”不算完成。
- 必练是教学优先级判断，需结合备考范围、先备地位、覆盖与训练收益；不等于必考。
- 只见一种机制时保留局部观察，不机械凑不同题型或固定条数。

## 统计约定

先列本批全部卷与参与本专题统计的卷，给出分组依据。分母是主题可比且纳入范围的去重卷数；不能依据是否出现某题型动态删除未命中卷。题意不清的小问排除，不因此自动删除整卷；受影响覆盖写清。

| 指标 | 计数方法 |
|---|---|
| 类别卷覆盖 | 已核验题意的直接命中单元对应的不同卷数 |
| 直接命中小问 | 对直接命中的规范 unit_id 去重 |
| 去重大题 | 对这些小问所属 question_id 去重 |
| 迁移单元 | 单独计数与列来源，不计入直接频率 |
| 展示次数 | 双版每节完整大题的实际出现次数，仅用于版面/一致性检查 |

同一小问可因明确的不同任务机制属于多个类别；类内重复记录去重，跨类总体按集合并集复算。直接与迁移不能在同一类别内同时赋给同一小问。只有 task_status=verified 的小问进入有效计数；solution_status 为 conflict/missing/pending 时必须报告解答状态，不能声称数学已审校。

不设默认“高频”阈值，先报告覆盖 x/N 与单元数；如使用高频等级，显式记录本次定义和理由。N 小或只有一卷时改称本批/单卷出现，不作跨校稳定性判断。

## 教学决策

为每个建议题组说明：先备能力→目标能力→每题新增障碍→通过标准→未通过时补什么→通过后接什么。优先改变一个主要障碍；多障碍综合题说明承接关系。

例如学生要先交出射影、垂足或方向向量再计算；动点题另需给参数域、极值/存在性检验和合法取等点。具体标准从本题推导生成，不能套给不含这些任务的题。

课堂表现只在有作答证据时描述；频率、任务难度、规则分和实际失分率各自标明，不互相替代。
