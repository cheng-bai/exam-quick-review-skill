# 低返工执行流程

用于PDF到教研成果、分类重跑、分册、多版本与断点续作。只导出或只评估时走相应短路径，不机械执行全部阶段。

## 先确定本次模式

| 请求 | 执行范围 | 应复用什么 |
|---|---|---|
| 从PDF开始做成果包 | 清点→转录校对→底稿→分析分类→所需产品→验收 | 已有可信转录、来源、解析、校订与工具 |
| 分类太细/缺少题型，重跑汇编 | 重新比较原题与必要解析，重编映射、导读、题序 | 完整题干、题图、有效解析；旧分类仅查漏 |
| 从某册再拆/抽一册 | 声明母集、选题与覆盖模式，再编制 | 当前册对应的题目ID与修订版本 |
| 定稿MD输出PDF | 冻结内容，渲染与验收 | 不重复OCR、分类和整批求解 |
| 做汇编说明与统计图 | 读取完整专题并恢复来源，冻结样本后制作 | 分类质量合格时沿用；不把去题源学生PDF当唯一底稿 |
| 总结项目/评估框架 | 核实已有来源与产品，交付报告或流程设计 | 不自动生产未要求的专题说明和图包 |

从文件和上下文能确定的信息直接采用；工程名称、文件修改时间和当前日期不能代替学年。单卷可做卷内分析，不宣称跨校共性。只要一版就不因流程示例增加所有版本。

## 共用底稿与关联表

完整题干、选项、小问、必要图和源解析保存一次，使用现有`交接记录.json` v1或等价项目底稿；旧台账无需为格式统一重录。外接本工具时提供ID适配副本或映射，不修改原题。

- 题目身份：规范question_id、paper_id、origin_id与原题号。规范ID不含册内题号、题型名或会变化的路径。
- 来源：原件/原页/题块位置、文件哈希；同卷不同文件合并，联考卷与参加学校分开关联。
- 内容：题干、图、源答案解析和补解分开；人工修订有前后文本、依据和修订版本。
- 状态：识别、题意、答案、数学复核、分类、显示与平台各自记录；只有缺解、冲突、实际疑点或明确审校请求才触发相应数学重算。
- 教研：知识对象、数学任务/方法、形式、难度及依据、关联类和训练角色分别记录。
- 讲义配置：母集ID、引用题目ID与修订、主归类、关联小问、排序、重复展示、版本合同。不要在每份讲义维护独立题干。

已有个人校订优先保留；重复OCR的机器稿不自动覆盖。题干修订须回写任务底稿/修订副本，不能只补PDF或最终回复。

## 三个冻结关口

1. **范围冻结**：当前母集、来源卷、考试范围、输出版本和覆盖模式有记录。源卷范围与专题范围分别标识。
2. **分类冻结**：代表题能解释共同结构、识别依据、处理路线、条件变化；单题类有教学理由。新规则先试代表样板，修正后全量；用户已确认的规则不反复等待确认。
3. **产品冻结**：题目修订、分类映射、题序、版本内容合同与统计样本确定，之后再批量导出。冻结是可追踪版本，发现数学错误仍须修正并使相关产物失效。

分类采用“专题→数学题型→题目形式→难度梯度”。形式不替代题型；同机制只改数值不另起类，实质不同的任务不为了合并而强称共性。完整大题按主训练目标归档，跨类关注小问用关联索引。

## 拆册必须写清集合合同

| 模式 | 要检查什么 |
|---|---|
| partition / 互补划分 | 每册是母集子集；各册交集为空；并集等于母集 |
| union_cover / 并集覆盖 | 允许交集；各册是母集子集；并集等于母集 |
| selection / 代表选编 | 允许只选部分；报告未选题，不声称全覆盖 |

“允许重复”选择union_cover或selection；只说“并集是原讲义”不推断必须互斥。每册内重复展示不增加唯一题数，跨册总原题数取并集。题意不清的题保留待核附录去向；答案冲突但题意明确者可归类并标注解答待核。

若存在“某专题96题版”和“全量159题版”，母集必须引用实际版本及题目集合；题数相近、同名、目录嵌套均不能证明范围相同。学校覆盖、完整大题、小问、展示次数分别统计。

## 分阶段放行与返工

| 阶段 | 放行依据 | 失败时回到哪里 |
|---|---|---|
| 收卷/转录 | 输入可读；题号、选项、小问、必要图可回源 | 只校对受影响原页/题块；无法确定处待核 |
| 数学证据 | 原解析与题意对应；缺解/冲突有去向 | 只补证或重算疑点及受依赖小问，不全量重解 |
| 分类样板 | 目录可理解，同练有共性，练习有梯度 | 调整映射和导读；不是先排完整PDF再改分类 |
| 全量编制 | 母集覆盖、重复、双版题序与内容合同通过 | 回到底稿或产品配置，重建受影响类/册 |
| 汇编说明 | 样本、分母、三图和选题指引同源 | 修来源/分类/统计，不单改图中数字 |
| 导出 | 公式真实渲染，图与题块完整，显示可读 | 改对应版式；不删题或缩小到不可读来过检 |
| 交付 | 统一入口、最新状态与恢复依据明确 | 修链接或产物后重跑受影响检查 |

只有用户明确要求在样板处停下审批，才将批准作为下一阶段条件；否则自主完成范围内的内部验收和后续工作。必要判断无法确定时问关键问题，继续无关部分。

## 修改后的依赖失效

把输入哈希/修订、分类、难度、来源映射、样本集合、题序、版本合同、版式分别登记。产物保存构建时用到的依赖快照；不只记生成日期。

| 变化 | 通常重建 | 通常可复用 |
|---|---|---|
| 题干/图/有效条件 | 含该题的相关讲义、分析/说明证据、HTML/PDF；条件影响归类/难度时同步统计 | 不含该题的产品、未变原始OCR |
| 答案解析修订 | 教师稿、引用该解的报告；影响题意/难度/分类时同步相关产品 | 确认不受影响的纯题目稿 |
| 分类/主考点或题序 | 目录、导读、相关汇编、统计、说明与导出 | 题干、图、有效解析 |
| 难度 | 排序、难度表图、说明和受影响讲义 | 不依赖难度的源题与原解析 |
| 来源/学校归组/专题样本 | 来源索引、学校统计、图和说明；含来源的稿 | 不含来源且题序不变的学生题面 |
| 版式/主题 | 对应HTML/PDF与显示检查 | 内容、分类、统计；不重做数学 |

构建先写任务work临时路径，验证后替换对应正式文件，保留恢复依据。未通过的新稿不更新“当前成品”入口。断点续作先回读清单与输入哈希，复用未变阶段。此技能提供规则与检查工具，不声称自动调度器已实现。

## 按用途验收

- 学生练习：必要图、完整选项小问和中性分类；无提示版本隔离答案、解法标签及含答案源链接。已明确授权的含分析版沿用内容合同，名称和风险说明准确。
- 教师备课：题后答案解析，原解/补解/勘误/待核可辨，与对应学生版同题同序。
- 工作台识别：按`xdf-workbench-student-pdf`的专用合同导出，不能把去图稿当完整练习。上传需已有授权；匹配数、题块、原题对应与分类层级分别实测。
- 网页报告：按内容长度设计首屏、阅读区与详细依据，不机械套通用图纸模板。可展开正文仍完整保留；检查文件/锚点、筛选等实际交互、桌面和手机溢出。别把过小字号或极密表格当成“完整”。

结构检查、数学复核、视觉审阅和平台实测分开报告。可用且获准时由独立agent复核代表分类、来源与疑点；不可用时做第二遍自查并记录限制。无学生作答时只给条件式选题建议，不声称学生真实薄弱或教学效果已验证。

## 批次清单与检查工具

多册/多版/续跑才需要`批次清单.json`；题目仍以`records_path`指向的交接记录为准。最小可运行合成示例见[batch-fixture.json](../examples/batch-fixture.json)，不可作为真实交付材料。

| 字段 | 含义 |
|---|---|
| schema_version、batch_id、records_path | 当前为1；批次身份；相对清单路径的现有v1题目记录 |
| scopes | 每项id、question_ids；母集唯一ID集合，包含需交代的待核原题 |
| products | id、scope_id、variant、question_ids；列表是实际展示顺序，可重复；同序双版可填same_order_as |
| coverage | id、scope_id、product_ids、mode；mode为partition、union_cover或selection；同一组引用相同母集的产品 |
| revisions | 输入键→非空版本/哈希字符串，例如stem:Q1、classification、layout:student；执行者根据真实变化更新 |
| artifacts | id、product_id、path、depends_on（输入键→构建时版本），可选sha256；正式/待核状态另存，不靠名字推断 |

```sh
python3 <技能目录>/scripts/check_records.py <批次目录>/交接记录.json --check-files
python3 <技能目录>/scripts/check_batch.py <批次目录>/批次清单.json --check-files
```

批次工具只读文件，输出各册唯一题量/展示次数、覆盖缺口/交集、题序冲突和已声明依赖中的过期产物。`--check-files`另验产物路径和可选哈希；路径相对清单。退出0=无结构错误且无已知过期，1=错误，2=过期。恢复构建后更新依赖快照并重跑。它不推断未声明依赖，也不把清单题号齐全当作PDF题块完整；完整题面、数学、公式图和分类仍需对应检查。
